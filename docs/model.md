# モデル

2D 平面ひずみ（圧延方向 x・板厚方向 y、板幅方向は無限）。すべて板幅 1 m あたり、SI 単位。
出口面（剛体ロールの最小ギャップ）が x = 0、板厚中心が y = 0。

## 参考文献との対応

B. Banerjee, *Material Point Method Simulations of Fragmenting Cylinders*, arXiv:1201.2439 (2012)
— Uintah の MPM で、鋼製円筒の破片化を解いた論文。このアプリが借りているもの:

| 論文 | このアプリ |
|---|---|
| 陽解法 MPM（格子で運動量、粒子で状態） | 同じ。形状関数は 2 次 B スプライン、転送は MLS-MPM / APIC |
| 亜弾性-塑性（偏差応力の速度形 + 状態方程式の圧力、半径方向リターン） | 偏差応力は Jaumann 回転 + 弾性試行 + J2 リターン、圧力は p = −K ln J |
| Johnson-Cook 流動応力 σy = (A + Bεpⁿ)(1 + C ln ε̇*)(1 − T*ᵐ) | 同じ（4340 鋼の定数も論文の値）。冷延材向けに Swift 則も |
| MTS 流動応力 | 未実装 |
| von Mises / GTN 降伏条件（空孔率 f） | 両方（`damage.yield`、既定 von Mises）。論文との違いは下の「GTN」 |
| Johnson-Cook 損傷 εf = [D1 + D2 exp(D3 σ*)][1 + D4 ln ε̇*][1 + D5 T*] | 同じ（σ* = η = σm/σeq） |
| Hancock-MacKenzie εf = 1.65 exp(−1.5 σ*) | 同じ |
| 分岐（Drucker の安定条件・音響テンソルの特異）による破壊 | 両方を表示の量に。音響テンソルの特異は判定にも選べる（`damage.model = 'localization'`、既定は使わない）。下の「分岐の指標」 |
| 破壊した粒子: 応力を 0 にする（または別の速度場に移す） | 「応力をすべて失う」と「圧縮だけ受け持つ」を選べる。別の速度場は未実装 |
| Mie-Grüneisen 状態方程式・断熱温度上昇 | 状態方程式は使わない（冷間・低速なので線形の体積弾性で十分）。断熱温度上昇は `material.chi`（Taylor-Quinney、既定 0 = 室温一定） |

圧延のために足したもの: 剛体ロールとの摩擦接触、Cockcroft-Latham 基準（圧延の割れで最もよく使われる）、
三軸度の下限（Bao-Wierzbicki: η < −1/3 では損傷しない）、押し込み装置、前後方張力。

## 1 ステップ

1. **P2G**: 質量と運動量（APIC のアフィン項と応力項 −Δt V σ (4/h²)(xᵢ − xₚ) を含む）を格子へ。
   同時に、各節点について「寄与する粒子のロールへの食い込み（表面までの距離 − 粒子の半径）」の最小値を記録
2. **格子更新**: 速度 = 運動量 / 質量。食い込む粒子を持つ節点で、ロールに近づく向きの相対速度を消し、
   接線方向は Coulomb 摩擦（|vt| ≤ μ|vn| なら固着、超えたら μ|vn| だけ減らす）。この力積がロールの荷重・トルク。
   同じ力積を格子の列ごとに集めたものが接触面の圧力・摩擦応力の分布（フリクションヒル）で、区間は列を中心に
   幅 h（区間の端が列に重なると丸めで 0〜2 列が入り、分布がギザギザになる）。中立点は摩擦応力が +x（入口側で
   ロールが板を引き込む）から −x に変わる位置: 入口からの累積が最大になる区間と次の区間の間で 0 を線形補間する
3. **G2P（1 回目）**: 速度と速度勾配 L（= APIC の C）。体積の扱い（下の「体積の平均化」）のため、壊れていない点が
   体積速度 tr L・弾性の体積 f = ln J − εv・緩和の割合 β を質量重みで格子へ
4. **G2P（2 回目）**: 体積速度 θ = （格子で平均した tr L）+ Σᵢ w βᵢ (f̄ᵢ − f_p)/Δt を粒子に戻し、J ← J exp(Δt θ)、
   F ← √(J_new/J_trial) (I + ΔtL) F。位置を進め、構成則と損傷

## 構成則

- 偏差応力 s: Jaumann 回転 s ← s + Δt(Ws − sW)、弾性試行 s ← s + 2GΔt dev(D̄)（D_zz = 0、s_zz も持つ）。
  D̄ = sym L + ½(θ − tr L) I₂ は体積速度を体積の扱いの θ に置き換えたもの。偏差応力と圧力が同じ体積変化を見るので、
  弾性域では平面ひずみの σzz = ν(σxx + σyy) がちょうど成り立つ（誤差 6e-13。以前は σzz −156 MPa に対し ν(σxx + σyy) −2 MPa）
- 圧力 p = −K ln J（J = det F）
- J2: q = √(3/2 s:s) > σy なら q − 3GΔεp = σy(εp + Δεp) を安全化 Newton で解き、s を (1 − 3GΔεp/q) 倍
- ひずみ速度は計算上の値に `millSpeed / rollSpeed` を掛けた実機換算で速度依存則に入れる
- 断熱温度上昇（`material.chi` > 0）: 塑性仕事の χ が熱になり、熱は逃げない（伝導なし）。ΔT = χ w J / (ρ0 cp)
  （w は現在の体積あたりの塑性仕事、J で基準体積あたりに、ρ0 は質量スケーリング前の密度）。温度は Johnson-Cook の
  流動応力の (1 − T*^m) と損傷の D5 に効く。比熱 cp は材料ごと（4340 は論文の Cp(T) の室温の値 455 J/(kg·K)）。
  シートに溜まった熱は χ × 塑性仕事に一致する（`tools/checks/heating.mjs`）。数値は `docs/validation.md`「断熱温度上昇」

## 体積の平均化（ロッキング対策、`numerics.volumetric`）

塑性流れは非圧縮なので、粒子ごとの体積比 J から圧力を出すと格子が拘束されすぎる（体積ロッキング: 標準 6 セルで荷重 6.5 kN/mm、
バイト内に η > 1 の偽の引張、延性材なのに偽の亀裂）。

**'rate'（既定）**: 1 ステップごとに体積速度 tr L だけを格子で平均する（状態の J は平均し直さない）。平均で消えない「格子が解けない
弾性の体積」 f = ln J − εv の差は、塑性の点でだけ節点の平均へ緩和する: θ = θ̄ + Σᵢ w βᵢ (f̄ᵢ − f_p)/Δt、
β = c · 3K Δεp / σeq（1 ステップあたり、1 で頭打ち）。これは塑性の割線粘性 σeq/(3ε̇p) を使った圧力射影の安定化
（Bochev–Dohrmann–Gunzburger）で、β を節点で対称にしているので Σ m f が保存され、一様な場は変わらない。
弾性域では 0、Δt によらず、効く範囲は一定のセル数。εv（GTN の塑性の体積）は平均しない。破壊した点と J ≤ 0 の点は平均に入れず、
自分の tr L を使う（亀裂の開口が隣の点の体積に漏れないように）。c は `volRelax`（1、教科書の値）、ロール面から 2h 以内だけ
`volRelaxContact`（5）。

**c = 5（ロールの近く）は暫定**: 今の接触は食い込む粒子の 3×3 の節点すべてを拘束するので、表面から約 1.5 セルの帯がロールの
法線方向に固定される（「既知の限界: 接触」）。帯の中の格子で解ける体積の非整合を、ロールの近くだけ強く緩和して逃がしている。
5 は標準 6 セルで以前の荷重（4.30 kN/mm、これ自体が帯による約 25 % の硬化を含む）に合わせた 1 ケースの調整で、接触を直す
T27 の後に 1 に戻して測り直す。

**'total'**: 以前の J-bar（試行の全体積比 J を毎ステップ格子で平均して置き換える）。状態を毎ステップならし直すので、
圧力の拡散 D ≈ h²/(4Δt)（16 セルで 0.024 m²/s、1 パスで約 11〜15 mm）になり、厚板の板厚中心の σm/2k が
−0.27 / −0.22 / −0.14（12 / 16 / 24 セル）と格子で動き Δt にも依存、偏差応力とも不整合だった。比較用に残す（ビット単位で以前と同じ）。

試して採らなかった案（`docs/validation.md`「体積の平均化」に数値）: 材料に付いた格子・区画での J-bar（6 セル 5.31 kN/mm、表層の
η ≈ 0.7、GTN の f 0.40、40 % 圧下・4 セルで偽の亀裂）、背景セルの増分 F-bar（6.40 kN/mm、16・24 セルで発散）、
緩和なしの速度の平均化（不安定、偽の亀裂 636）。

## GTN（空孔率）

`damage.yield = 'gtn'` のとき、J2 の代わりに Gurson-Tvergaard-Needleman の降伏条件（論文の式 13〜17、定数は Table 1）:

- Φ = (q/σf)² + 2 q1 f* cosh(3 q2 σm / (2σf)) − (1 + q3 f*²)、f* = f（f ≤ fc）、fc + k(f − fc)（f > fc）。
  q1 1.5、q2 1.0、q3 2.25、k 4、fc 0.05
- 空孔率 ḟ = (1 − f) tr Dp + A ε̇M、A = fn/(sn√(2π)) exp(−½((εM − εn)/sn)²)。fn 0.1、εn 0.1、sn 0.3。初期空孔率 f0 0.005
- 返り写像（`gtnReturn`、Aravas 1987 の形）: 塑性ひずみ増分を Δεv I/3 + Δεq n（n は試行の偏差の向き）とし、
  q = q_tr − 3GΔεq、σm = σm_tr − KΔεv。Φ = 0 と関連流れ Δεv ∂Φ/∂q = Δεq ∂Φ/∂σm を (Δεq, Δεv) の Newton で解く。
  Φ の f は刻みの初めの値、σf は母材ひずみ εM + ΔεM（(1 − f)σf ΔεM = qΔεq + σmΔεv）で陰的。f = 0 なら J2 の返り写像と一致
  （`tools/checks/gtn.mjs`）
- 圧力: 粒子ごとに塑性体積ひずみ ev = Σ Δεv を持ち、p = −K (ln J − ev)。体積の平均化（'rate'）は ev を平均せず、
  弾性の体積 ln J − ev だけを緩和する
- 判定を「空孔率が fc に達する」（`damage.model = 'gtn'`）にすると f/fc が損傷の指標。空孔率は GTN の降伏条件のときだけ進む
- 母材の相当塑性ひずみ εM を `ep` として持ち、流動応力と JC・HM・CL の積算に使う

**論文との違い:**
- **核生成は既定で「平均応力が引張のときだけ」**（`gtn.nucleation = 'tension'`、論文の式は `'always'`）。
  論文の対象（爆発で膨らむ円筒）はほぼ全域が引張で差が出にくいが、圧縮が主の圧延では大きく違う:
  標準条件（6 セル・板長 8 mm）で `'always'` だと f が 0.033 まで増えて荷重が 4.31 → 3.98 kN/mm（−7.7 %。以前の J-bar では f 0.045・−36 %）になる。
  粒子の剥離・割れで空孔が開くには界面の引張が要るので、圧延では引張のときだけにする
- 初期空孔率は一様（論文は平均 0.005・標準偏差 0.001 の正規分布）。冷延材なら f0 = 0 も選べる
- 論文の返り写像は偏差応力の半径方向の戻しと空孔率の陽的な更新。ここでは (Δεq, Δεv) を連立で解く

**荷重の変化**（体積の平均化 'rate'、標準条件 6 セル）: f0 = 0.005・引張のときだけ核生成で −0.8 %（4.308 → 4.274 kN/mm）、常に核生成で −7.7 %（3.976、f の最大 0.033）。
cosh 項は σm の符号によらないので降伏面は圧縮側でも縮む（f = 0.005 で q/σf = √(1 + q3 f² − 2 q1 f cosh(1.5 σm/σf)) は σm = −σf で 0.98、−2σf で 0.92）が、
空孔はロールバイトの圧縮で潰れる（f 0.005 → 0.001〜0.002）ので効きは小さい。以前の J-bar（'total'）では −9 % / −36 % だった。その大半は J を平均して εv を
平均しないことによる圧力のむら（K Δεv、バイト内の隣との差の最大 347 MPa）と圧力の拡散の結果で、GTN の性質ではない。数値は `docs/validation.md`「GTN」

## 損傷と亀裂

塑性ひずみ増分 Δεp があるたびに 3 つの指標を積算する（表示用に全部、判定は選んだ 1 つ。GTN の空孔率 f/fc も判定に選べる）:

- Johnson-Cook: D += Δεp / εf(η, ε̇*, T*)
- Hancock-MacKenzie: D += Δεp / (1.65 exp(−1.5η))
- Cockcroft-Latham: D += max(σ1, 0)/σeq · Δεp / C_crit

η が下限（既定 −1/3）以下なら JC と HM は積算しない。欠陥（`weak`）の粒子は増分を 1/延性 倍する。
判定の指標が 1 に達した粒子は破壊し、以後は偏差応力を持たない。圧力は「圧縮だけ」なら p ≥ 0 のときだけ残す。
破壊した粒子が、未変形の格子で 2 つ以内に既存の亀裂の粒子を持てばその亀裂に加え、なければ新しい亀裂とする。

**非局所化（`damage.nonlocalLength` = ℓ、既定 0 = 粒子ごと）**: ℓ > 0 のとき、JC・HM・CL の各ステップの増分を
格子で平均してから足す（J-bar と同じ要領: 質量重みで節点へ → B スプラインの重みで粒子へ、を n 回。
n = max(1, round(2 (ℓ/h)²))。1 回の平均は各軸に標準偏差 0.71 h だけ広げ、n 回で 0.71 h √n ≈ ℓ）。一様な場は変わらず、
Σ m·ΔD は保たれる（`tools/checks/nonlocal.mjs`）。破壊した粒子は平均に入らない。自分では塑性変形していない粒子も、
隣の損傷を受け取って破壊しうる。空孔率（GTN）と分岐の判定は粒子ごとのまま。格子依存の比較は `docs/validation.md`「非局所化」

応力状態エクスプローラ（画面）は、各粒子の (η, εp, D) を εp が 0.004 進むごと（または塑性変形中に η が 0.1 変わるごと）に
記録し、破断軌跡 εf(η) の上に描く。η が変わる経路では D = ∫ dεp/εf(η) が 1 になる点は曲線の上とは限らないので、
同じ損傷を今の η の比例負荷で与えるひずみ D·εf(η) も点線で描く（D = 1 で曲線に載る）。Cockcroft-Latham の εf(η) は
平面ひずみ J2 の σ1 = σm + σeq/√3 を使った近似 C/(η + 1/√3)。

## 張力

前後方張力は板の端面にかかる応力として与える。合計はちょうど応力 × 端の列の実際の高さ（粒子の上下の広がりで測る）で、
それを板の両端の長さ h0 の**掴み**（巻取り・払い出しのリールに掴まれた部分。`Sim.gripCols` 列、板の半分を超えない）の粒子に分けてかける。
粒子の分け前は 重み × 粒子の変形後の高さ（|F·e_y|·dp）で、重みは端の列で最大・掴みの内端で 0 に近づく一次（`Sim.gripWeight`）。
合計が σ × 端の列の高さになるよう掴み全体で割り戻す（`Sim.gripScale`。掴みの列の高さが違っても、空洞があっても保たれる。`Sim.endLoad` が合計）。
初めの実装は未変形の高さで掛けていて、圧延後の頭端では出側の板に σf/(1−r) が掛かっていた。
端の 1 列だけに線荷重でかけていたときは、出側の降伏を超える前方張力で頭端の列がちぎれた（600 MPa で頭端の 2 列が 1 ms で 13 mm 飛んだ）うえ、
最初の亀裂がいつも頭端の列に出た。**張力が実際に掛かっている間**、その端の掴みの点は損傷を表示するが破壊しない（`Sim.inGrip`。
頭端は前方張力が掛かる前、尾端は後方張力を外した後は普通の点）。

- 後方張力: 計算の開始から立ち上げ、尾端が入口面（x = −Lc）に達したら立ち下げる（ロールの後ろの板が無くなれば引く相手も無い。
  以前は抜けた板を引き戻していた）。立ち下げは尾端がバイトを抜ける時間（Lc / 入側速度）以内
- 前方張力: 頭端が出側の測定位置を越えたとき（巻取りに掴まれたとき）から立ち上げる。尾端が抜けた後も掛かり続けるので、抜けた板は加速する
  （後方張力と非対称。巻取りの速度制御は無い）
- 立ち上げは `rolling.tensionRamp`（既定: 弾性波が板の長さを 10 回伝わる時間 10·L/c。質量スケーリング 1e4・L = 16 mm で約 2.7 ms）。
  階段状に掛けると応力波が鳴り、それだけで頭端が割れることがあった。押し込み装置を外す瞬間はまだ階段状（後方張力を押し込み装置が受けていた分）
- 端の列が格子の外に出たら張力は 0（`Diagnostics.frontTension` / `backTension` は実際に掛けている応力）
- 測定（`tools/checks/tension.mjs`、6 セル）: 出側の板の体積平均の σxx は前方張力 100 MPa に対して 105 MPa（圧延後の板では粒子の F の高さの和が
  粒子の間隔より約 3 % 小さく、体積が板厚をやや小さく数えるため）、後方張力 100 MPa に対して入側の板（掴みの先）で 96〜102 MPa。
  掴みの中では応力が 0 から張力まで上がる
  頭端が大きく歪む条件（μ 0.25・r 35 %・Al）でも前方張力 100 MPa に対して 94 MPa
- 張力の差をロールの摩擦で支えきれないと板はロールに対して滑る（スキッド）。前方張力が勝てば先進率が数十 % に、
  後方張力が勝てば先進率が負（μ 0.04・前後 200 MPa で −15 %）になる。先進率が 0〜10 % を外れたらこれを疑う

## 分岐の指標（`src/mpm/bifurcation.ts`）

論文の破壊条件のうち、材料の不安定を見る 2 つ。どちらもその点が直前のステップで塑性流れしたとき（von Mises）だけ評価する。

- **局所化（音響テンソルの特異）**: J2・等方硬化の弾塑性接線
  C_ep = K I⊗I + 2G I_dev − 6G²/(3G + H) n̂⊗n̂（n̂ = s/|s|、H = dσy/dεp）について、面内の帯の法線 n ごとの
  音響テンソル A = n·C_ep·n の det を弾性の値で割り、n について最小にした値（表示 `loc`）。
  1 は弾性、0 以下でせん断帯が生じうる。面内の偏差応力の主軸系で cos 2θ の凹の二次式になるので閉形式で解く。
  面内の塑性流れ（s_zz = 0）では最小は H/(3G + H)、帯は主軸から ±45°（平面ひずみの J2 は H ≤ 0 でしか帯が出ない。
  Rudnicki & Rice 1975）。s_zz ≠ 0 だと帯は出にくくなる。
  体積の平均化 'rate' では平面ひずみの s_zz が整合するので（バイト内の塑性の点の |s_zz|/|s| の中央値 0.019。以前の J-bar では 0.188）、
  理想塑性（Swift n = 0、速度係数なし、6 セル）で loc の最小は 4.6e-9 とほぼ 0（以前の J-bar では 2.7e-6）。
  H = 0 ちょうどでは ratio ≤ 0 の判定が丸め（±2.2e-16）で決まるので、帯の判定には軟化（H < 0）が要る
- **Drucker の安定条件**: σ̇ : Dp（表示 `drucker` は σ̇ : Dp / ε̇p²、単位 MPa）。比例負荷では H に等しく、負なら不安定。
  1 ステップだけでは弾性試行のノイズが大きいので、直近の塑性ステップについて Σ Δσ:Δεp / Σ Δεp² を
  重み（1 − 1/64）ⁿ で平均する。Δσ は Jaumann で回した前のステップからの変化
- 判定に「せん断帯が生じうる」（`localization`）を選ぶと、塑性の点で det A / det Aₑ ≤ 0 になったら破壊する。
  硬化する材料（今の材料はすべて）では起きない。熱軟化（T13）や GTN の空孔の軟化が入ると意味を持つ

限界: 接線は速度に依存しない（その時点のひずみ速度での H だけ）。客観応力速度の応力の項（σ/G のオーダー、Rice 1976）は入れていない。
GTN の降伏条件では評価しない（`loc` = 1、`drucker` = 0）。
以前の J-bar（'total'）では平面ひずみの σzz が不整合で、バイト内の塑性の点の s_zz/|s| が中央値 0.16〜0.19、入口の手前と出口の先では約 0.8 になり、

面外の偏差応力で大きめ）。表示は ±0.05 なので約半分は弾性の点と同じ濃い青に飽和し、帯に近い点（小さい値）を見分ける範囲になっている。
`loc` は表層（εp が大きく H が小さい）で最も小さい。`drucker` をバイトを 8 等分した中央値は 1650, 700, 540, 455, 570, 360, 240, −1130 MPa で、

## 既知の限界（改善の候補）

- **体積ロッキング**: 上の「体積の平均化」（'rate'）で抑えている。ロールの近くの係数 5 は接触の帯を補う暫定の値（T27 で 1 に）。
  粒子の尺度の圧力のむらは以前の J-bar より大きい（バイト内の隣との差の平均 6 セルで 23 対 12 MPa、10 セルで 13 対 6）ので、
  損傷の指標は 1.5〜2 倍になる（標準の最大損傷 0.011 対 0.006）。厚板の中心の σm/2k はまだ格子で動く（8/12/16/24/32 セルで
  −0.11 / +0.04 / +0.13 / +0.20 / +0.23、J-bar なしと同じ傾向、Hill の +0.39 への外挿は未確定）。校正は `tools/checks/volumetric*.mjs`
  と `rolling-smoke.mjs`（荷重の上限 5 kN/mm でロッキングを落とす）
- **接触**: 食い込む粒子を持つ節点すべてに拘束をかけるので、表面から約 1.5 セルの帯が拘束される。
  ロールの力はこの帯に体積力として入るので、**最外層の粒子の応力は接触面の力を表さない**
  （p = −n·σ·n の積分が荷重の約 6 割。`docs/validation.md`「接触面の分布」）。分布は節点の力積から出す
- **質量スケーリング**: 既定 1e4 倍（周速 1 m/s）。慣性の圧力 ρ s V² r は流動応力の数 % 程度
- **亀裂の開口**: 速度場は 1 つなので、破壊した粒子の両側は格子を通じて同じ速度に引っ張られる。
  きれいな亀裂面の開口には複数速度場（論文の「別の材料に移す」）が要る
- **2D**: 板幅方向が無いので、耳割れ（エッジクラック）は扱えない
- **剛体ロール**: ロール偏平（Hitchcock）は無い
- **GTN の圧力のむら**: 以前の J-bar（'total'）では J̄ を平均し ev を平均しないので K Δev のむらが出た（常に核生成でバイト内の隣との
  差の最大 347 MPa）。'rate' は弾性の体積だけを緩和するので 88 MPa（`tools/checks/volumetric-gtn.mjs`）
