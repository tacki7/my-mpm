# モデル

2D 平面ひずみ（圧延方向 x・板厚方向 y、板幅方向は無限）。すべて板幅 1 m あたり、SI 単位。
出口面（剛体ロールの最小ギャップ）が x = 0、板厚中心が y = 0。

## 参考文献との対応

B. Banerjee, *Material Point Method Simulations of Fragmenting Cylinders*, arXiv:1201.2439 (2012)
— Uintah の MPM で、鋼製円筒の破片化を解いた論文。このアプリが借りているもの:

| MTS 流動応力 | 未実装 |

圧延のために足したもの: 剛体ロールとの摩擦接触、Cockcroft-Latham 基準（圧延の割れで最もよく使われる）、
三軸度の下限（Bao-Wierzbicki: η < −1/3 では損傷しない）、押し込み装置、前後方張力。

## 1 ステップ

1. **P2G**: 質量と運動量（APIC のアフィン項と応力項 −Δt V σ (4/h²)(xᵢ − xₚ) を含む）を格子へ。
   同時に、縁がロールに入った粒子（表面までの距離 − 粒子の変形後の半分の高さ < 0）が、ロール側の節点と法線方向に h/2 以内の節点
   （最寄りの行）に「接触する」印を付ける（下の「接触」）
2. **格子更新**: 速度 = 運動量 / 質量。印の付いた節点で、ロールに近づく向きの相対速度を消し、
   接線方向は Coulomb 摩擦（|vt| ≤ μ|vn| なら固着、超えたら μ|vn| だけ減らす）。続けて、縁の入った粒子の縁がまだロールへ
   向かうなら、足りない法線速度をその粒子の印の付いた節点に足す（下の「接触」）。これらの力積がロールの荷重・トルク。
   同じ力積を格子の列ごとに集めたものが接触面の圧力・摩擦応力の分布（フリクションヒル）で、区間は列を中心に
   幅 h（区間の端が列に重なると丸めで 0〜2 列が入り、分布がギザギザになる）。中立点は摩擦応力が +x（入口側で
   ロールが板を引き込む）から −x に変わる位置: 入口からの累積が最大になる区間と次の区間の間で 0 を線形補間する。
   零点がバイトの中（−Lc < x < 0）に無ければ中立点は null で、理由を `neutralState` に出す（`sticking`: バイトのどの区間でも
   |τ| < μp で弧の全体が固着。入口・出口の近くは p → 0 で滑るので、実際の圧延ではほとんど出ない、`backward` / `forward`: 摩擦が全体で板を引き込む / 押し戻す、`none`: 接触なし）。区間の窓は
   入口の 6 セル手前から出口の 6 セル後ろまでで、両端は次の列まで広げる（板の頭端は入口の 100 ステップ手前 `startOffset`（約半セル）から始まるので、
   入口は列の途中にある。1e-6 の余裕を持たせた floor / ceil。以前の round は 179.999… を 179 にして窓が 1 列ずれた）
3. **G2P（1 回目）**: 速度と速度勾配 L（= APIC の C）。体積の扱い（下の「体積の平均化」）のため、壊れていない点が
   体積速度 tr L・弾性の体積 f = ln J − εv・緩和の割合 β を質量重みで格子へ
4. **G2P（2 回目）**: 体積速度 θ = （格子で平均した tr L）+ Σᵢ w βᵢ (f̄ᵢ − f_p)/Δt を粒子に戻し、J ← J exp(Δt θ)、
   F ← √(J_new/J_trial) (I + ΔtL) F。位置を進め、構成則と損傷

## 構成則

- 偏差応力 s: Jaumann 回転 s ← s + Δt(Ws − sW)、弾性試行 s ← s + 2GΔt dev(D̄)（D_zz = 0、s_zz も持つ）。
  D̄ = sym L + ½(θ − tr L) I₂ は体積速度を体積の扱いの θ に置き換えたもの。偏差応力と圧力が同じ体積変化を見るので、
  弾性域では平面ひずみの σzz = ν(σxx + σyy) がちょうど成り立つ（誤差 6e-13。以前は σzz −156 MPa に対し ν(σxx + σyy) −2 MPa）
- 圧力 p = −K ln J（J = det F）
- J2: q = √(3/2 s:s) > σy なら q − 3GΔεp = σy(εp + Δεp) を安全化 Newton で解き、s を (1 − 3GΔεp/q) 倍
- ひずみ速度は計算上の値に `millSpeed / rollSpeed` を掛けた実機換算で速度依存則に入れる。相当ひずみ速度 ε̇ = √(2/3 dev D̄ : dev D̄) を点ごとに持ち（`Sim.rate`・`Sim3.rate`、流れていない点も）、
  色の量「ひずみ速度」（`field=rate`・`f3=rate`）はそれを描く。定常のバイトの平均は平面ひずみの目安 (2/√3) ln(h0/h1) vR / Lc（標準条件で 665 1/s）の
  0.89 倍（2 次元 6 セル 593 1/s）、3 次元（4 セル・板幅 2 mm）は 562 1/s。入口の手前と出口の先では小さい（`tools/checks/strain-rate.mjs`）
- 断熱温度上昇（`material.chi` > 0）: 塑性仕事の χ が熱になり、熱は逃げない（伝導なし）。ΔT = χ w J / (ρ0 cp)
  （w は現在の体積あたりの塑性仕事、J で基準体積あたりに、ρ0 は質量スケーリング前の密度）。温度は Johnson-Cook の
  流動応力の (1 − T*^m) と損傷の D5 に効く。比熱 cp は材料ごと（4340 は論文の Cp(T) の室温の値 455 J/(kg·K)）。
  シートに溜まった熱は χ × 塑性仕事に一致する（`tools/checks/heating.mjs`）。数値は `docs/validation.md`「断熱温度上昇」

## 体積の平均化（ロッキング対策、`numerics.volumetric`）

塑性流れは非圧縮なので、粒子ごとの体積比 J から圧力を出すと格子が拘束されすぎる（体積ロッキング: 標準 6 セルで荷重 6.5 kN/mm、
バイト内に η > 1 の偽の引張、延性材なのに偽の亀裂）。

**'rate'（既定）**: 1 ステップごとに体積速度 tr L だけを格子で平均する（状態の J は平均し直さない）。平均で消えない「格子が解けない
弾性の体積」 f = ln J − εv の差は、塑性の点でだけ節点の平均へ緩和する: θ = θ̄ + Σᵢ w βᵢ (f̄ᵢ − f_p)/Δt、
β = c · 3K Δεp / σeq（1 ステップあたり、1 で頭打ち）。これは塑性の割線粘性 σeq/(3ε̇p) を使った圧力射影の安定化
（Bochev–Dohrmann–Gunzburger）で、β を節点で対称にしているので Σ m f が保存され、一様な場は変わらない。
弾性域では 0、Δt によらず、効く範囲は一定のセル数。εv（GTN の塑性の体積）は平均しない。J ≤ 0 の点と、引張の（p ≤ 0 の）破壊した点は
平均に入れず、自分の tr L を使う（亀裂の開口が隣の点の体積に漏れないように）。圧縮を受ける破壊した点（閉じた亀裂）は平均に入る
（下の「既知の限界」の圧縮を受ける破壊した点。T46）。c は `volRelax`（1、教科書の値）、ロール面から 2h 以内は
`volRelaxContact`（既定 1）。

**ロールの近くの c**: T21 では 5 にしていた。当時の接触（'stencil'）は食い込む粒子の 3×3 の節点すべてを拘束し、表面から約 1.5 セルの帯が
ロールの法線方向に固定されていたので、帯の中の格子で解ける体積の非整合をロールの近くだけ強く緩和して逃がしていた
（5 は標準 6 セルで以前の荷重 4.30 kN/mm に合わせた 1 ケースの調整。'stencil' で 1 にするとロックして 5.07 kN/mm）。
T27 で接触を 'surface' に直したので 1 に戻した（標準 6 セル 3.20 kN/mm、T31 の後は 3.24。5 のままだと 10 セルで表層の行が中心より薄くなり、
`volumetric.mjs` の質量スケーリングの差も +0.039 で外れる）。係数は比較用に残す

**'total'**: 以前の J-bar（試行の全体積比 J を毎ステップ格子で平均して置き換える）。状態を毎ステップならし直すので、
圧力の拡散 D ≈ h²/(4Δt)（16 セルで 0.024 m²/s、1 パスで約 11〜15 mm）になり、厚板の板厚中心の σm/2k が
−0.27 / −0.22 / −0.14（12 / 16 / 24 セル）と格子で動き Δt にも依存、偏差応力とも不整合だった。比較用に残す（ビット単位で以前と同じ）。

試して採らなかった案（`docs/validation.md`「体積の平均化」に数値）: 材料に付いた格子・区画での J-bar（6 セル 5.31 kN/mm、表層の
η ≈ 0.7、GTN の f 0.40、40 % 圧下・4 セルで偽の亀裂）、背景セルの増分 F-bar（6.40 kN/mm、16・24 セルで発散）、
緩和なしの速度の平均化（不安定、偽の亀裂 636）。

## 接触（`numerics.contact`）

ロールは解析的な剛体の円柱で、接触は格子の節点の速度の射影で課す（「1 ステップ」の 1・2）。どの節点に課すかで結果が大きく変わる。
数値は 'rate'・標準条件・6 セル（`docs/validation.md`「接触」）。

- **'stencil'（T27 まで）**: 縁がロールに入った粒子の 3 × 3 の節点すべて。1 面あたり節点 3 行（表面から約 1.5 セルの帯）が
  ロールの法線方向の速度に固定され、帯の中の材料は板厚方向に自由に縮めない（6 セルでは板厚方向に自由な節点が 1 行しか残らない）。
  帯がロールと一緒に動くので、最外層の粒子はロールの圧力の一部しか受け持たず（以前の J-bar で 57 %）、表層の行はほとんど
  薄くならずに中心の行が代わりに薄くなり（板厚の減りの相当ひずみ 表層 −0.02・中心 0.68。一様なら 0.33）、荷重は約 25 % 硬かった
  （以前の J-bar で 4.28 kN/mm）。'rate' の係数 1 ではロックする（5.07 kN/mm）
- **'surface'（既定）**: 縁が入った粒子の**ロール側**の節点と、ロールの法線方向に粒子から h/2 以内の節点（最寄りの行）だけ。
  それだけだと、拘束した節点はロール表面の法線速度で、より深い自由な節点は収束の遅い内部の速度で動くので、粒子の速度（両者の補間）は
  ロール表面より遅れ、噛み込みで粒子がロールに 0.04〜0.06 dp 沈んで戻らない（出側が約 1 % 厚い。格子で減らない）。そこで
  格子更新の後、縁の入った粒子の縁の法線方向の相対速度 (v − u)·n − rp D_nn（u はロール表面の速度、n はロール中心 → 粒子、
  rp は粒子の変形後の高さの半分、D_nn は法線方向の伸び速度: 粒子自身が薄くなる分は縁を動かさない）が負なら、
  足りない分を「その粒子の印の付いた節点への重みの和」で割った法線速度をそれらの節点に求め、節点ごとに要求を質量重みで平均して足す。
  印の付いた節点は、表面の速度ではなく場がその位置で持つ速度を運ぶことになる。係数は無い。この力積もロールの荷重・トルク・圧力分布に入る。
  この法線の力積も Coulomb の上限に入れる: 格子更新で各ロールが節点に残したすべり速度を覚えておき、法線の速度 dv を足した節点が滑っていれば、
  すべりを μ·dv だけ（止まるまで。止まったら滑りはちょうど 0）減らす。以前は射影の法線の力積だけで上限を決めていたので、滑る節点の摩擦は
  標準条件で 0.984 μ（バイトの中だけなら 0.988 μ）だった（荷重の 1〜3 % の法線の力積の分。T31、検査は `tools/checks/contact-friction.mjs`）
  T27 の時点の標準 6 セルで荷重 3.20 kN/mm（T31 の後は 3.24、板長 16 mm で 3.236）、最外層がロールの圧力の 88 % を受け持ち、縁の沈みは 0.003 dp 以下、出側板厚 0.751 mm、
  層ごとの板厚の減り 0.32 / 0.35 / 0.31（表層 / 1/4 / 中心）

上下のロールが同じ節点に効くとき（上下の隙間が 1〜2 セルの粗い格子。2 セル・40 % は URL でだけ作れる）: 2 つの射影はどちらも接触前の速度から計算し、
節点には面が近い方のロールだけを当てる（ちょうど同じ距離の板厚中心では 2 つの平均）。ロールに付いて行かせる要求もロールごとに足し込む。
以前は上のロールの後に下のロールを当て、要求も 1 つの和に混ぜていたので、対称な圧延が非対称になった（2 セル・40 % でトルクが 9.9 % 違い、
中心の行が 0.23 dp ずれた。'stencil' の接触では 4 セルでも 0.9 %・0.5 dp）。検査は `tools/checks/contact-symmetry.mjs`。
両方のロールに拘束された節点（2 セル、w = 0.5）では、ロールごとの滑りの予算を w·s_k とするのは近似。Coulomb の不等式 |J_t| ≤ μ J_n は
ロールごとに成り立ち、NaN も出ない（T31 のレビューで確認）。

### 摩擦の定式化を文献と照らす（Jacobs 2025）

L. Jacobs, "Modelling Friction in Cold Rolling", Univ. Twente, 2025（冷間圧延の摩擦の博士論文。スラブ法 + 混合潤滑のモデルと、
パイロットミル・実機の測定）と、この計算の摩擦の扱いを 1 項目ずつ比べた（2026-09-22）。

| 項目 | 論文 | この計算 | 判定 |
|---|---|---|---|
| Coulomb の法則 | \|τ\| ≤ μ σn、滑るとき τ = μ σn で相対すべりの逆向き（式 1.15、2.82・2.83） | 節点ごとの力積で \|J_t\| ≤ μ J_n。接線の相対速度が μ\|v_n\| より小さければ固着（相対速度 0）、大きければ μ\|v_n\| だけ減らす（`projectRoll`）。followRoll の法線の力積も上限に入れる | 同じ法則の離散形。滑る節点で J_t / J_n = μ を `contact-friction.mjs` が毎回確かめる |
| 垂直応力 | ロール面の法線方向の応力 σn（鉛直の σy ではない。σn = σy − τ tan θ の関係、式 1.11〜1.14） | 法線はロール中心 → 節点。圧力・摩擦はこの法線と接線に分けて記録。スラブ法（`slab.ts`）も p は法線、荷重は ∫(p + τ tan φ) dx（τ は符号付き） | 一致 |
| 中立点 | 入口側は板がロールより遅く摩擦は出口向き、中立点で向きが反転 | 向きは節点とロール面の相対速度の符号で決まり、中立点は与えない（結果として出る）。τ の零点から読む | 一致（フリクションヒルと中立点は `docs/validation.md`） |
| 先進率 | (v_out − v_roll) / v_roll（式 1.5） | `exit.speed / rollSpeed − 1` | 一致 |
| 平面ひずみの降伏 | σx − σy = (2/√3) σ_flow（von Mises） | スラブ法 2k = (2/√3) σy、MPM は 3 次元の J2 を平面ひずみで解く | 一致 |
| ロール偏平 | Hitchcock R' = R0 (1 + 16(1−ν²)/(πE) · F / (w Δt))（式 2.11）。R' < 2 R0 なら FEM と合う | `hitchcockRadius()` が同じ式。標準条件の 2 スタンド目で R' = 1.63 R | 一致。R' > 2 R0（極薄・硬い板）では円弧の仮定そのものが怪しい |
| 固着・せん断の上限 | τ ≤ k（式 2.84 τ = m k、Ekelund・Tselikov の固着域） | 断面・3 次元: 上限は置かない（表層が降伏して τ は k を超えられない）。平面図: min(μ p, k) を明示 | 問題なし。μ 0.25 でスラブ法は μp > k の警告、MPM は荷重比 1.01 |

**式は間違っていない。** 違うのは「何をモデルにしていないか」:

- **μ は定数**。論文の主題は混合潤滑（τ = A τ_asp + (1 − A) τ_lub、油膜・粗さ・速度で変わる）で、実機の μ は速度とともに下がる。ここには無い
- **μ の大きさ**。論文の測定では潤滑した冷間圧延の μ は 0.015〜0.03。既定の 0.08 は乾いた・潤滑の悪い条件に当たる。
  標準の形（R 100・h0 1・r 25 %）はスラブ法で μ 0.02 だと中立点が無く（噛めない）、μ 0.03 で先進率 0.3 %。
  実機に近い μ を試すなら R/h0 を大きく（R 250・h0 0.5 で μ 0.03 でも先進率 2.9 %）か、圧下率を小さく
- **異方性（Hill48）・粘性せん断の発熱・ロールの非円形の変形**は無い。論文は、von Mises の古典的なスラブ法が μ 0.03 でも荷重を 20 % 以上
  過大に見積もり、荷重と先進率を同時には合わせられないと報告している（4.7 節）。この計算の比較相手のスラブ法も同じ古典的なものなので、
  「スラブ法と合う」ことは実機と合うことを意味しない
- 論文自身も MPM（LAMMPS、Ganzenmüller）を使うが、対象は粗さの突起のプラウイング（μm の尺度）で、バイト全体ではない

試して採らなかった案（`tools/contact-compare.mjs`、案を並べたコミット `wip(contact)` の版、`docs/validation.md`「接触」）:
ロールの中の節点だけ（沈み 0.5 dp、出側 0.84 mm）、ロール面から h/2 以内の節点だけ（沈み 0.22 dp）、ロール側の節点だけ（上の沈み）、
縁の入った粒子の速度だけを止める（粒子の位置が F と食い違い、10 セルで表層の行の間隔が 23 % 詰まる）、
粒子の縁でなく中心をロールに付いて行かせる（外側の行を必要以上に縮める）。

## GTN（空孔率）

`damage.yield = 'gtn'` のとき、J2 の代わりに Gurson-Tvergaard-Needleman の降伏条件（論文の式 13〜17、定数は Table 1）:

- Φ = (q/σf)² + 2 q1 f* cosh(3 q2 σm / (2σf)) − (1 + q3 f*²)、f* = f（f ≤ fc）、fc + k(f − fc)（f > fc）。
  q1 1.5、q2 1.0、q3 2.25、k 4、fc 0.05
- 空孔率 ḟ = (1 − f) tr Dp + A ε̇M、A = fn/(sn√(2π)) exp(−½((εM − εn)/sn)²)。fn 0.1、εn 0.1、sn 0.3。初期空孔率 f0 0.005
- 返り写像（`gtnReturn`、Aravas 1987 の形）: 塑性ひずみ増分を Δεv I/3 + Δεq n（n は試行の偏差の向き）とし、
  q = q_tr − 3GΔεq、σm = σm_tr − KΔεv。Φ = 0 と関連流れ Δεv ∂Φ/∂q = Δεq ∂Φ/∂σm を (Δεq, Δεv) の Newton で解く。
  Φ の f は刻みの初めの値、σf は母材ひずみ εM + ΔεM（(1 − f)σf ΔεM = qΔεq + σmΔεv）で陰的。f = 0 なら J2 の返り写像と一致
  （`tools/checks/gtn.mjs`）
- 圧力: 粒子ごとに塑性体積ひずみ ev = Σ Δεv を持ち、p = −K (ln J − ev)。体積の平均化（'rate'）は ev を平均せず、
  弾性の体積 ln J − ev だけを緩和する
- 判定を「空孔率が fc に達する」（`damage.model = 'gtn'`）にすると f/fc が損傷の指標。空孔率は GTN の降伏条件のときだけ進む
- 母材の相当塑性ひずみ εM を `ep` として持ち、流動応力と JC・HM・CL の積算に使う

**論文との違い:**
- **核生成は既定で「平均応力が引張のときだけ」**（`gtn.nucleation = 'tension'`、論文の式は `'always'`）。
  論文の対象（爆発で膨らむ円筒）はほぼ全域が引張で差が出にくいが、圧縮が主の圧延では大きく違う:
  標準条件（6 セル・板長 8 mm、T31 の前に測った）で `'always'` だと f が 0.033 まで増えて荷重が 3.22 → 3.00 kN/mm（−6.8 %。T27 の接触の前は 4.31 → 3.98・−7.7 %、以前の J-bar では f 0.045・−36 %）になる。
  粒子の剥離・割れで空孔が開くには界面の引張が要るので、圧延では引張のときだけにする
- 初期空孔率は一様（論文は平均 0.005・標準偏差 0.001 の正規分布）。冷延材なら f0 = 0 も選べる
- 論文の返り写像は偏差応力の半径方向の戻しと空孔率の陽的な更新。ここでは (Δεq, Δεv) を連立で解く

**荷重の変化**（体積の平均化 'rate'、標準条件 6 セル）: f0 = 0.005・引張のときだけ核生成で −0.8 %（4.308 → 4.274 kN/mm）、常に核生成で −7.7 %（3.976、f の最大 0.033）。
cosh 項は σm の符号によらないので降伏面は圧縮側でも縮む（f = 0.005 で q/σf = √(1 + q3 f² − 2 q1 f cosh(1.5 σm/σf)) は σm = −σf で 0.98、−2σf で 0.92）が、
空孔はロールバイトの圧縮で潰れる（f 0.005 → 0.001〜0.002）ので効きは小さい。以前の J-bar（'total'）では −9 % / −36 % だった。その大半は J を平均して εv を
平均しないことによる圧力のむら（K Δεv、バイト内の隣との差の最大 347 MPa）と圧力の拡散の結果で、GTN の性質ではない。数値は `docs/validation.md`「GTN」

## 損傷と亀裂

塑性ひずみ増分 Δεp があるたびに 3 つの指標を積算する（表示用に全部、判定は選んだ 1 つ。GTN の空孔率 f/fc も判定に選べる）:

- Johnson-Cook: D += Δεp / εf(η, ε̇*, T*)
- Hancock-MacKenzie: D += Δεp / (1.65 exp(−1.5η))
- Cockcroft-Latham: D += max(σ1, 0)/σeq · Δεp / C_crit

η が下限（既定 −1/3）以下なら JC と HM は積算しない。欠陥（`weak`）の粒子は増分を 1/延性 倍する。
判定の指標が 1 に達した粒子は破壊し、そのステップのうちに偏差応力を捨てる（保存した応力は次の p2g で格子に配られるので、
捨てるのが 1 ステップ遅れると、割れた点が隣を 1 回余計に引っ張る。`tools/checks/failed-stress.mjs`）。圧力は「圧縮だけ」なら
p ≥ 0 のときだけ残す。亀裂の記録の η・σ1・σeq は捨てる前の値。基準が「判定しない」のときは破壊させず、損傷 D の表示と最大損傷は
JC・HM・CL の 3 つの最大（3 つはどの基準でも積算している）。
破壊した粒子が、未変形の格子で 2 つ以内に既存の亀裂の粒子を持てばその亀裂に加え、なければ新しい亀裂とする。

**非局所化（`damage.nonlocalLength` = ℓ、既定 0 = 粒子ごと）**: ℓ > 0 のとき、JC・HM・CL の各ステップの増分を
格子で平均してから足す（J-bar と同じ要領: 質量重みで節点へ → B スプラインの重みで粒子へ、を n 回。
n = max(1, round(2 (ℓ/h)²))。1 回の平均は各軸に標準偏差 0.71 h だけ広げ、n 回で 0.71 h √n ≈ ℓ）。一様な場は変わらず、
Σ m·ΔD は保たれる（`tools/checks/nonlocal.mjs`）。破壊した粒子は平均に入らない。自分では塑性変形していない粒子も、
隣の損傷を受け取って破壊しうる。空孔率（GTN）と分岐の判定は粒子ごとのまま。格子依存の比較は `docs/validation.md`「非局所化」

応力状態エクスプローラ（画面）は、各粒子の (η, εp, D) を εp が 0.004 進むごと（または塑性変形中に η が 0.1 変わるごと）に
記録し、破断軌跡 εf(η) の上に描く。η が変わる経路では D = ∫ dεp/εf(η) が 1 になる点は曲線の上とは限らないので、
同じ損傷を今の η の比例負荷で与えるひずみ D·εf(η) も点線で描く（D = 1 で曲線に載る）。Cockcroft-Latham の εf(η) は
平面ひずみ J2 の σ1 = σm + σeq/√3 を使った近似 C/(η + 1/√3)。

## 亀裂の面（`numerics.crackFields`、既定 'dfg'、T74）

'none'（T74 までの既定）では速度場が 1 つで、亀裂の両側の点は周りの節点を共有し、格子を通じて同じ速度に引かれる。破壊した点は応力を持たないが、
両側の健全な点は引かれ続けるので、亀裂の面の隣が荷重を持ち続ける（中心割れの面を渡る σyy が平均 180〜220 MPa）。

'dfg'（Homel & Herbold 2017 の場の勾配で分ける方式）:
- φ = 1 を破壊した点に置き、節点に G_i = Σ V_p φ_p ∇w(x_i − x_p)（破壊した点の向き）と、破壊した点の重心 C_i（重み w m）を作る
- G_i ≠ 0 の節点で、点が C_i より G_i の向きに先にあれば、その節点では第 2 の場（亀裂の向こう側）、そうでなければ第 1 の場。
  点ごと・ステンシルの 9 節点ごとに決める（`crackSide = 'centroid'`、既定）。論文の方法は、点の勾配 g_p と G_i の向きの比べ（'gradient'）。
  中心線の 2 行の破壊した帯では g_p が上下から打ち消して 0 に近く、分かれない節点が残る（面を渡る σyy が平均 125 MPa・最大 670 MPa 残る）ので、既定にしない
- 第 2 の場は節点の配列の後ろ半分（節点 + nNodes）に置く。P2G・格子更新（ロールの接触・followRoll・押し込み）・体積の平均化（'rate' の
  gJ・gJe・gB・gMv）・G2P は、どれも点がその節点で乗っている場で行う。荷重・トルク・接触の分布は両方の場を数える
- 両方の場が質量を持つ節点では、何より先に摩擦なしの接触: 法線 n = G/|G|（節点の側 → 亀裂の向こう）、近づくとき（(v1 − v2)·n > 0）は
  法線の速度を重心の速度に揃える（運動量を保つ）、離れるときは何もしない。**接触は格子の更新の頭で 1 回だけ**（ロールの射影・followRoll の前）。
  ロールと followRoll が場ごとに速度を変えた後に、場がまた近づく節点がある: 閉じた切れ目（4 セル・板長 6 mm）で、両方の場が質量を持つ
  節点ステップの 34 %（77 142 / 227 618）、近づく速さは最大でロールの周速の 13.6 %。重なりは出ない（切れ目の両側の隣り合う列の間隔は
  最後まで 1.000 dp 以上）。直すなら followRoll の後にもう一度接触を解く
- `assignFields` が回るのは、破壊した点のステンシルの箱（基点の列 c0〜c1・行 r0〜r1、節点は c1 + 2・r1 + 2 まで）と、そこへステンシルが
  届く点だけ。破壊した点は型付き配列の検索（indexOf）で拾い、足し合わせる順番は全点を回るときと同じ。'centroid' の側は重みを使わず、
  9 節点を 1 回回って決める。第 2 の場を回るループ（格子の更新・場の接触・体積の平均の割り算）も、この箱の節点番号の区間
  [c0 nyN + r0, (c1 + 2) nyN + r1 + 3) の中だけ（第 2 の場に質量があるのは箱の中だけなので、結果は全体を回るのとビット一致）。
  中心割れ・12 セルで、最初の亀裂から後の 1 ステップの 5 %（T60 の前は 10 %）。亀裂が増えた後まで含めた 3 000 ステップの平均では 3 %（0.020 / 0.60 ms、T65）
- 破壊した点が 1 つも無いステップは第 2 の場を作らず、'none' とビット一致。場は毎ステップ `failed` から作り直すので、タンデムの
  移し替えで引き継ぐものは増えない
- 側の割り当てと接触の法線は、どちらも G から決まるので、G の符号をまとめて逆にしても整合は保たれる。片方だけが逆だと
  （試作で起きた: 割り当ては g_p·G で G の符号によらず、法線だけが逆だった）面どうしが重なる。検査は法線だけを逆にした写しで FAIL する
- 実測（`docs/validation.md`「亀裂の面」）: 中心割れ（12 セル）の面を渡る σyy は平均 223 → −8 MPa・最大 457 → 37 MPa、
  破壊した点は 34 → 14（面が引張を遮るので周りの損傷が伸びない）。前方張力で切れた面の隣の σxx は +500 ステップで 419 → 121 MPa。
  閉じた切れ目は重ならず、出口の先で少し開く
- 平面図モデルにも同じ選択（同じパラメータ）で入る（下の「平面図モデル」）
- 限界: 二次の B スプラインの台（3 セル）より細い亀裂の周りでは、節点ごとの割り当てなので
  片側の点の一部が向こう側の場に入ることがある（分かれ方は格子に依存する）。**損傷の非局所の平均**（`damage.nonlocalLength` > 0）は
  場を分けないので、亀裂の両側の点の損傷の増分が平均し合う。**タンデムの止まり方**: 板が切れたかの判定（破壊した点が板厚を貫く列）は、
  面が開いて破壊した点が少ないと成り立たない（前方張力・4 セル・2 スタンドで 'none' は破壊した点 20・`separated`、'dfg' は 6 点で、
  切れた先が格子の外へ出て `lost`・失われた質量 9.6 %。どちらも 1 スタンドで止まる）。T74 で 'dfg' を既定にしたので、
  タンデムの止まり方は既定で `lost` になる（`docs/validation.md`「タンデム」）

## 板厚方向の対称モデル（2 次元）（`rolling.halfThickness`、既定は全厚）

板とロールが板厚の中心 y = 0 について対称なので、上半分だけを解ける（3 次元モデルの 1/4 モデルと同じ考え。`src/mpm/solid/sim3.ts` の対称面）。
条件パネルの「板厚方向」で「対称（上半分・ロール 1 本）」、URL は `sym=1`、ツールは `--half`。点が半分なので約 2 倍速い。
既定（全厚・ロール 2 本）の計算は 1 ビットも変えない（`tools/checks/half-thickness.mjs` が既定の 6 セル・8 mm の荷重を、測った機械ではビット一致・CI の Linux では V8 の exp / log の最後の 1 ビットの差が育つので 1e-9 で留める）。

- **格子**: 中心面の 1 セル下から始める（iy = 0 が y = −h のゴースト行、iy = 1 が面の上の節点、iy = 2 が y = +h）。板は y ∈ [0, h0/2]
  に播き、格子の行は上半分の分（偶数セルなら全厚の格子の上半分そのものなので、点の位置は全厚と一致する）。ロールは上だけ
  （`rolls.length === 1`。`setRolls`・ロール偏平・圧下率一定はそのまま上のロールに効く）
- **ゴースト行の折り返し**（`foldGhosts`）: P2G の後、ゴースト行の和（質量・運動量・押し込みの深さ・押し込み印）を鏡像の行 iy = 2 に足す
  （運動量の y は符号を反す）。面の節点 iy = 1 は vy = 0。格子の更新のあと、ゴースト行は iy = 2 の速度を鏡で写して持つ（`mirrorGhosts`。
  vy は逆符号）ので、面の近くの点の G2P は全厚と同じ 9 節点を読む。J-bar（`gJ`・`gJe`・`gB`・`gMv`）と損傷の非局所の平均も同じく
  折り返して、平均のあと鏡へ戻す。`followRoll` がゴースト行を読むのはロールが面から 1 セル以内に来たとき（板厚 2 セル以下）だけ
- **点の更新**: y < 0 へ出た点は y = −y に戻す（面を貫かない）。格子の下端の判定は無し（面の下は鏡）
- **読み**: 荷重・トルクは上のロールの値（全厚はロール 2 本の平均。板全体の値で、ロール 1 本あたり）。出側板厚は上の面の高さの 2 倍
  （`exitMeasure`・`areaThickness`）、圧力分布は上のロールの、塑性仕事・運動エネルギーは 2 倍して板全体の値に。中心面の η（`midplane.ts`）は
  行 0（面の上の行）、表面は最上行。タンデムの移し替えは出側板厚（面の上の面積の 2 倍）を次のスタンドの h0 に渡し、格子の上の質量は
  半分の板の分（`remap` の `hOn`）
- **亀裂**（`crackFields: 'dfg'`）: 中心割れは面の上の行から始まる。破壊した点のステンシルが届く面の節点は、面の中の亀裂の上にあって、
  材料と鏡像が摩擦なしの接触で会う: 近づくとき（vy < 0）は vy = 0 に留め、離れるとき（vy > 0）は自由。この片側の規則が無いと面は
  開けない（面を渡る σyy が全厚の 1 場の 180 MPa 台のまま）。場の割り当ての G・C もゴースト行を折り返して作る。面の節点では
  G_y = 0 なので、重心と同じ x にある点（全厚では上下の対で決まる）は決め方が要る: |x − C_x| ≤ 1e-9 h の点は G_x の向きの先
  （第 2 の場）と決める。これが無いと破壊した点が x で 2 つの場に裂けて膨らみ（J > 1・圧力 0）、面の隣が 138 MPa を持つ。
  実測は `docs/validation.md`「板厚方向の対称モデル」
- **絵**: 断面の画面は下半分を鏡で写して描く（点・主応力の向き・追っている点の丸の印。下のロールは幾何に鏡像として渡す）、
  y = 0 に点線の継ぎ目。下半分の点をクリックすると鏡の元の点（上半分）が選ばれる。俯瞰の板の輪郭も鏡で下へ
- **効かないもの**: 平面図（板厚は点の状態で、もともと対称）と 3 次元（1/4 モデル）。`solidMode.ts` の `NOT_IN_3D` に `sym`
- 限界: 中心面の亀裂の面の扱い（片側の接触・x の同点の決め方）は全厚と同じ数にはならない（全厚では面の節点の G_y が上下で打ち消して
  丸めで決まる）。全厚と半分の中心割れは、破壊した点の数と面の応力の傾向で比べる（`docs/validation.md`）

## 張力

前後方張力は板の端面にかかる応力として与える。合計はちょうど応力 × 端の列の実際の高さ（粒子の上下の広がりで測る）で、
それを板の両端の長さ h0 の**掴み**（巻取り・払い出しのリールに掴まれた部分。`Sim.gripCols` 列、板の半分を超えない）の粒子に分けてかける。
粒子の分け前は 重み × 粒子の変形後の高さ（|F·e_y|·dp）で、重みは端の列で最大・掴みの内端で 0 に近づく一次（`Sim.gripWeight`）。
合計が σ × 端の列の高さになるよう掴み全体で割り戻す（`Sim.gripScale`。掴みの列の高さが違っても、空洞があっても保たれる。`Sim.endLoad` が合計）。
初めの実装は未変形の高さで掛けていて、圧延後の頭端では出側の板に σf/(1−r) が掛かっていた。
端の 1 列だけに線荷重でかけていたときは、出側の降伏を超える前方張力で頭端の列がちぎれた（600 MPa で頭端の 2 列が 1 ms で 13 mm 飛んだ）うえ、
最初の亀裂がいつも頭端の列に出た。**張力が実際に掛かっている間**、その端の掴みの点は損傷を表示するが破壊しない（`Sim.inGrip`。
頭端は前方張力が掛かる前、尾端は後方張力を外した後は普通の点）。

- 後方張力: 計算の開始から立ち上げ、尾端が入口面（x = −Lc）に達したら立ち下げる（ロールの後ろの板が無くなれば引く相手も無い。
  以前は抜けた板を引き戻していた）。立ち下げは尾端がバイトを抜ける時間（Lc / 入側速度）以内
- 前方張力: 頭端が出側の測定位置を越えたとき（巻取りに掴まれたとき）から立ち上げる。尾端が抜けた後も掛かり続けるので、抜けた板は加速する
  （後方張力と非対称。巻取りの速度制御は無い）
- 立ち上げは `rolling.tensionRamp`（既定: 弾性波が板の長さを 10 回伝わる時間 10·L/c。質量スケーリング 1e4・L = 16 mm で約 2.7 ms）。
  階段状に掛けると応力波が鳴り、それだけで頭端が割れることがあった。押し込み装置を外す瞬間はまだ階段状（後方張力を押し込み装置が受けていた分）
- **「定常」は張力が全部かかってから**: 前方張力の立ち上げは「定常」の始まり（頭端が出側の測定位置を越えたとき）と同時に始まるので、立ち上げの間は
  `phase()` が 'adjusting' を返し、定常の平均に入れない（入れると荷重 +1.6 %・トルク +20 %。`docs/validation.md`「条件を振った検証」）。平面図は `tensionsOn()` の読みだけを平均する。
  `tensionsOn()` は直前のステップで掛けた張力で判定する（`updateTension` はステップの前の t、`phase()` はステップの後の t を見るので、1 ステップ分ずらす）
- 端の列が格子の外に出たら張力は 0（`Diagnostics.frontTension` / `backTension` は実際に掛けている応力）
- 測定（`tools/checks/tension.mjs`、6 セル）: 出側の板の体積平均の σxx は前方張力 100 MPa に対して 105 MPa（圧延後の板では粒子の F の高さの和が
  粒子の間隔より約 3 % 小さく、体積が板厚をやや小さく数えるため）、後方張力 100 MPa に対して入側の板（掴みの先）で 96〜102 MPa。
  掴みの中では応力が 0 から張力まで上がる
  頭端が大きく歪む条件（μ 0.25・r 35 %・Al）でも前方張力 100 MPa に対して 94 MPa
- 張力の差をロールの摩擦で支えきれないと板はロールに対して滑る（スキッド）。前方張力が勝てば先進率が数十 % に、
  後方張力が勝てば先進率が負（μ 0.04・前後 200 MPa で −15 %）になる。先進率が 0〜10 % を外れたらこれを疑う

## スラブ法（`src/mpm/slab.ts`、MPM の比較相手）

`karman()` は von Kármán の方程式 d(σx h)/dx = 2p(tan φ ∓ μ) を入口と出口から RK4 で積分する数値解、
`blandFord()` は同じバイトを小角（h = h1 + Rφ²、tan φ = φ）・2 tan φ (p − 2k) の項を省略・2k 一定で解いた閉形式
（柳本 潤「圧延理論－1（圧延概論・Karman の理論）」東京大学生産技術研究所、6 節と 5 節の式 29-1・29-2）。硬化する材料では
2k を張力の項だけ入口・出口の値、圧力は接触長の平均に取る（`tensionAt`）。標準条件で 2 つの解は先進率 1 %・中立点 0.3 %・∫p dx 0.4 % で一致し、
差は摩擦と噛み込み角とともに開く（μ 0.20 で先進率 2.9 %、圧下率 40 % で 7 %）。MPM はどちらに対しても荷重が 3〜7 % 高く、
中立点が 0.1〜0.2 mm 出口側に出る（弾塑性と慣性があるため。数値は `docs/validation.md`）。解析解は比較専用で、画面には出さない。

## 分岐の指標（`src/mpm/bifurcation.ts`）

論文の破壊条件のうち、材料の不安定を見る 2 つ。どちらもその点が直前のステップで塑性流れしたとき（von Mises）だけ評価する。

- **局所化（音響テンソルの特異）**: J2・等方硬化の弾塑性接線
  C_ep = K I⊗I + 2G I_dev − 6G²/(3G + H) n̂⊗n̂（n̂ = s/|s|、H = dσy/dεp）について、面内の帯の法線 n ごとの
  音響テンソル A = n·C_ep·n の det を弾性の値で割り、n について最小にした値（表示 `loc`）。
  1 は弾性、0 以下でせん断帯が生じうる。面内の偏差応力の主軸系で cos 2θ の凹の二次式になるので閉形式で解く。
  面内の塑性流れ（s_zz = 0）では最小は H/(3G + H)、帯は主軸から ±45°（平面ひずみの J2 は H ≤ 0 でしか帯が出ない。
  Rudnicki & Rice 1975）。s_zz ≠ 0 だと帯は出にくくなる。
  体積の平均化 'rate' では平面ひずみの s_zz が整合するので（バイト内の塑性の点の |s_zz|/|s| の中央値 0.019。以前の J-bar では 0.188）、
  理想塑性（Swift n = 0、速度係数なし、6 セル）で loc の最小は 4.6e-9 とほぼ 0（以前の J-bar では 2.7e-6）。
  H = 0 ちょうどでは ratio ≤ 0 の判定が丸め（±2.2e-16）で決まるので、帯の判定には軟化（H < 0）が要る
- **Drucker の安定条件**: σ̇ : Dp（表示 `drucker` は σ̇ : Dp / ε̇p²、単位 MPa）。比例負荷では H に等しく、負なら不安定。
  1 ステップだけでは弾性試行のノイズが大きいので、直近の塑性ステップについて Σ Δσ:Δεp / Σ Δεp² を
  重み（1 − 1/64）ⁿ で平均する。Δσ は Jaumann で回した前のステップからの変化
- 判定に「せん断帯が生じうる」（`localization`）を選ぶと、塑性の点で det A / det Aₑ ≤ 0 になったら破壊する。
  硬化する材料（今の材料はすべて）では起きない。熱軟化（T13）や GTN の空孔の軟化が入ると意味を持つ

限界: 接線は速度に依存しない（その時点のひずみ速度での H だけ）。客観応力速度の応力の項（σ/G のオーダー、Rice 1976）は入れていない。
GTN の降伏条件では評価しない（`loc` = 1、`drucker` = 0）。
以前の J-bar（'total'）では平面ひずみの σzz が不整合で、バイト内の塑性の点の s_zz/|s| が中央値 0.16〜0.19、入口の手前と出口の先では約 0.8 になり、
`loc` が H/(3G + H) より大きめに出ていた。下の分布の数値はその時のもの（'rate' では測り直していない）。

標準条件（6 セル、step 17000）のバイト内の流れている点で、`loc` は p05 3.4e-3・p50 0.043・p95 0.30（H/(3G + H) は 0.001〜0.02。
面外の偏差応力で大きめ）。表示は ±0.05 なので約半分は弾性の点と同じ濃い青に飽和し、帯に近い点（小さい値）を見分ける範囲になっている。
`loc` は表層（εp が大きく H が小さい）で最も小さい。`drucker` をバイトを 8 等分した中央値は 1650, 700, 540, 455, 570, 360, 240, −1130 MPa で、
バイトのほとんどで正、明確に負なのは最後の 1/8（出口の直前。ひずみ速度が下がって流動応力の速度係数が下がる、速度による軟化）と出口の先。
表示は ±2000 MPa（入口の角と出口の先に ±10⁵ MPa の外れ値がある）。前方張力のプリセット（6 セル、#4 の張力）でも `loc` は正のまま
（最小 1.2e-3、出口面の直前 y ≈ ±0.12 mm）で、最初の亀裂（Cockcroft-Latham、頭端の近く）の場所は指さない。

## 平面図モデル（耳割れ、`src/mpm/planview/`）

断面モデルには板幅が無いので耳割れは出ない。平面図モデルは板幅を解き、板厚方向は平均する別の 2D MPM（x 圧延方向・z 板幅方向）。
画面では表題の行の「平面図」で切り替える（T34、README「平面図」）。node からは `PlanSim`・`tools/planview.mjs`・`tools/checks/planview.mjs`。

- 粒子の状態に板厚 h を持つ。質量 m = ρ A0 h0、体積 V = A h（A は面内の F の行列式 × A0）
- 板幅の中央 z = 0 で対称: z < 0 のゴースト節点の質量・運動量を鏡の節点に（z 成分の符号を反転して）畳み、z = 0 の節点は v_z = 0（v_x は自由）、
  ゴースト節点には鏡映した速度を戻す。半幅だけ解き、端は自由
- 板厚: 隙間 h_gap(x) の 99 % より厚い点は隙間に合わせた D_yy = ln(h_gap/h)/Δt で試し、そこで σ_yy < 0（ロールを押す）なら接触（相補性）。
  そのとき σ_yy が接触圧 −p_c。そうでなければ平面応力で、σ_yy = 0 を満たす D_yy を括弧付きの割線法（二分法の予備つき、|σ_yy| ≤ 1 kPa）で解く。
  出口の先の弾性回復（隙間より少し薄くてもロールを押す点）も相補性で拾うので、接触が毎ステップ入れ替わらない
- 応力は 3D の偏差応力（s_xx, s_zz, s_xz, s_yy）で、断面モデルと同じ Jaumann 回転・弾性試行・J2 の半径リターン（material.ts）。
  圧力は体積比 J = det F · h/h0 から p = −K ln J。体積の扱いはこの 1 か所（`volumeRatio` / `pressureOf`）
- 面内のつり合い（板厚方向に積分）: ∂(h σ_ij)/∂x_j + 2τ_i + 2 p_c (−tan φ, 0) = 0。ロールの力は、傾いたロール面の圧力の x 成分
  −2 p_c tan φ（接触している点に陽的に）と、上下 2 面の Coulomb 摩擦。**摩擦は内力を入れた後に格子の上で解く**（接触の返り写像と同じ形）:
  接触している点が容量 2 min(μ p_c, k) A を重み w で節点に集め、節点の試行速度をロールの周速 (v_R, 0) へ、容量 × Δt / m まで近づける
  （それで滑りが消えれば固着、消えなければ容量いっぱいで滑る）。正則化は無く、Δt・質量スケーリングによらない。
  固着の上限 k = σy/√3 は、その点の塑性ひずみと、構成則と同じひずみ速度（実機速度換算）での値（静的な値の約 1.13 倍。バイト内の中央値）。
  以前の点ごとの摩擦は 1 ステップの力積を m|Δv| で頭打ちにしていたが、ステップ初めの滑りで判定するので、2τΔt/(ρ_s h) が滑りを
  超えるところで摩擦が黙って削られ、μ 0.3 の荷重が質量スケーリングで変わった（W 10 mm で ms 1e4 / 1e3 / 1e2 が 5.18 / 4.59 / 3.54 kN/mm）
- 押し込み装置・前後方張力・質量スケーリング・実機速度換算は断面モデルと同じパラメータ・同じ意味。張力は断面モデルと同じく掴み（長さ h0）に、
  端の列で最大・内端で 0 に近づく重みで分け、合計がちょうど σ × 端の列の断面（Σ 板厚 × 幅方向の間隔）になるよう割り戻す。
  張力が掛かっている間だけ掴みの点は壊れない
- 損傷は JC・HM・CL（GTN と分岐の指標は無い）。亀裂の記録は断面モデルと同じ形（y の代わりに z）
- 亀裂の面（`numerics.crackFields = 'dfg'`、既定、`crackSide` も同じ。T50）: 断面モデルの「亀裂の面」と同じ方式を x–z 面で。
  節点の配列の後ろ半分が第 2 の場で、P2G・対称面の畳み込み・摩擦の容量と格子の摩擦・押し込み・G2P（点の摩擦の取り分も）を、点がその節点で
  乗っている場で行う。場どうしの摩擦なしの接触は、畳んだ後の実の節点で、ほかの何より先に。**対称面**: 破壊した点の鏡像も数えるため、G と C も
  幽霊節点から鏡の節点へ（z 成分の符号を反転して）畳み、z = 0 の節点では G_z = C_z = 0、幽霊節点には鏡映した値を戻す
  （畳まないと、中央から入った切れ目の対称面の隣の 2 行が荷重を持ち続ける: 105 MPa、畳むと 10 MPa。`tools/checks/planview-crack-fields.mjs`）。
  体積の平均化は平面図には無く、板厚は点ごとの状態のまま（場の接触は面内だけ）。破壊した点が無ければ 'none' とビット一致。
  断面と同じく、接触は格子の更新の頭で 1 回だけで、摩擦と押し込みが場ごとに速度を変えた後に場がまた近づく節点がある:
  両方の場が質量を持つ節点ステップのうち、端から入れた切れ目で 4.6 %（近づく速さは最大で周速の 0.36 %）、中央から 4.6 %（0.50 %）、
  尾端のそば 10.6 %（1.1 %）。端と中央はすべて摩擦のある節点、尾端は摩擦か押し込みのある節点で、どちらも無い節点ではまた近づかない（検査）
- 摩擦が噛み込みの角の半分（α/2 ≈ 0.025）より小さくても、押し込み装置で一度噛ませれば μ 0.02 は減速しながら最後まで圧延される
  （断面モデルと同じ。T11）。μ 0 では押し込み装置が離れた後にロールに押し戻され、入側から格子の外へ出る。平面図モデルには
  stalled の判定が無いので、そのときも phase は done になる（圧延されてはいない。W 10 mm・板長 16 mm で確かめた）
- μ 0.3 では尾端が抜ける間（tail-out）、尾端の 2 列はバイトの中で引張になる（最大 W 10 mm で +305、W 20 mm で +503 MPa）が、
  接触は外れない（板長 12・16 mm、100 ステップごとに見て接触していない点 0）。以前の点ごとの摩擦では、尾端の列がロールに引き込まれて
  バイトの中で接触が外れていた（σxx +460〜480 MPa、板厚 = 隙間の 0.9999 倍）。摩擦を格子で解くようになって変わった

分かっていること（標準条件、W 20 mm、`docs/validation.md`「平面図モデル」）:

  3.96・4.39・4.33・4.18（W/h0 40 は板長 84 mm、60 は 120 mm。定常の窓は頭端・尾端から max(8 mm, 半幅)、T48）。スラブ法と比べるのは半幅平均（W/h0 ≥ 20 で 3.14〜3.21、+4〜6 %）。
  板幅方向の速度を 0 にする（平面ひずみ）と全列 3.17（+4.8 %）なので、荷重の読み方の誤りではない。中央が高いのは板幅方向の荷重の再配分で、
  中央の列は入口の手前と出口の先で圧延方向に圧縮され（端は引張で釣り合う）、W/h0 ≤ 20 では中立点の近くに幅方向の摩擦の丘もできる。

  **未検証**（比べる文献・解析解を見つけていない）
- 幅広がりは端ごとに W/h0 5・10 で 0.27 mm、20 で 0.17 mm、60 で 0.05 mm（半幅で）と、広い板ほど小さい（以前の「幅によらず約 0.2 mm」は、
  短い板で頭端の過渡を平均した値だった）。Wusatowski の式は補正係数なしの基本形で W/h0 が小さい範囲の経験式なので、W/h0 ≥ 20 との比較には使わない
- 延性が低いと端（引張の帯）から割れ、十分なら割れない。端の切り欠きがあるとその根元から割れる（体積の平均化の後の限界値は
  `docs/validation.md`「平面図モデル」の表）。
  **ただし割れは端に沿った帯になり、圧延方向に直角の形にはならない**: 端は長さ方向に同じ履歴をたどるので損傷が一様に溜まり、
  ほぼ同時に壊れる。割れの形を決めているのは「どこで損傷が 1 に達するか」で、亀裂の先端に応力が集まって先へ進むことではない
- **場を分けても（'dfg'）、端が一様なら耳割れは帯のまま**（T50 段 1、`docs/validation.md`「亀裂の面」の平面図の表）: 面の隣は荷重を降ろし、
  破壊した点は減る（CL 0.1 で帯の点が約 3 割少ない）が、帯の内側（板幅の中央寄り）はバイトの中で圧縮なので、先端が中へ進む駆動が無い。
  端に弱い点や延性のばらつきを入れると割れは短く分かれ、場を分けると破壊した点が約半分になって深さの向きに寄るが、直角には走らない。
  直角の耳割れには、割れ始めの場所の長さ方向のばらつき（端の延性のばらつき・介在物）と、先端の応力集中を解くこと（細かい格子、
  先端での損傷の扱い）が要る
- **体積の平均化**（`numerics.volumetric`、断面と同じ既定 'rate'。T63）: バイトの中では面内の発散が板厚の拘束 −D_yy に縛られるので体積ロッキングが出る。
  断面と同じように、面内の体積速度 θ = tr L（面内の 2 成分）を格子で平均し、格子で解けない弾性の体積 f = ln J = −p/K を節点の平均へ
  β = c·3K Δεp/σeq で緩和する（`volRelax`。ロールの近くの係数は平面図には無い）。板厚の速さ D_yy は点のまま（接触なら隙間、外なら平面応力）で、
  det F を exp(Δt θ) に合わせ、偏差の更新でも面内の trace を θ に置き換える。対称面では θ・f・β・質量を鏡の節点へ畳み（向きの無い量なので符号はそのまま）、
  割ってから幽霊節点へ戻す。亀裂の面（'dfg'）では場ごとに散布して読む。引張の破壊した点と J ≤ 0 の点は平均に入れず自分の率（T46 と同じ）。
  `numerics.jbar = false` で前の点ごとの計算に戻る（ビット一致）。平面図にあるのはこの方式だけで、
  `volumetric = 'total'`（断面に比較用で残している昔の J-bar）を選んでも平面図は同じように率を平均する。効き目と費用は `docs/validation.md`「体積の平均化（平面図）」:
  隣との圧力差の p95 が平均の 0.43 → 0.14、粒子ごとの三軸度のむらが 3〜4 割減、区間平均の荷重は数 % 以内、1 ステップ +16〜18 %。
  **耳割れは割れにくくなった**（むらの裾で先に壊れていた点が壊れない）ので、割れる限界値の例を測り直した

### 端の延性のばらつき（`plan.edgeScatter`、T52）

端が一様な材料だと、端はバイトの中で長さ方向にほぼ同じ履歴をたどるので損傷も一様に溜まり、耳割れは端に沿った 1 本の帯になる
（場を分けても同じ）。実機の耳割れが離れて並ぶのは、端の組織・介在物の帯・トリミングの傷が長さ方向にばらついているため。
そのばらつきを、**端の帯の延性を下げる条件**として入れる（組織を解いているのではない）。

- 端から `width` の帯にある点は、延性が **1 − `amount`·u** 倍（u ∈ [0, 1)）。`amount` = 0.2 なら延性 0.8〜1 倍。板厚方向・板幅方向には一様
- u は種と区画の番号から引く擬似乱数（mulberry32 を (seed, cell) に掛けたもの）。**同じ条件は同じ板**になるので、条件の URL を共有すれば同じ絵が出る
- 区画の番号は**未変形の板の長さ方向の座標**から `floor(頭端からの距離 / length)`。`length`（相関長）は圧延方向に 1 つの値が続く長さで、
  0 なら点ごと。材料の話（介在物の多い／少ない帯の尺度）なので格子とは別に決められる
- 延性は初期化のとき 1 回だけ掛かる（欠陥の延性と同じ扱いで、`duct` に入って損傷の限界値を割る）。計算時間は変わらない
- **既定は `amount` = 0（無効）**。そのとき延性に触らないので、今までの結果とビット一致（`tools/checks/planview-edge-scatter.mjs`）

分かっていること（`docs/validation.md`「端の延性のばらつき」）: 一様な端の 1 本の帯が、大きさ 20 %・幅 1 mm・相関長 1 mm で
**1〜2.5 mm の割れ 3 本前後**に分かれる（種 6 つ、間隔の中央値 2.13 mm）。大きさを上げるほど多く短く、相関長を伸ばすほど少なく長くなる。

限界:

- **点ごと（`length` = 0）だと割れの間隔を格子が決める**（h 0.5 → 0.25 mm で 2 → 10 本）。相関長はこれを断つために要る
- **相関長を入れても格子依存は残る**（h 半分で 3 → 4 本、間隔の中央値 2.00 → 1.62 mm）。残りは材料の場ではなく、割れの先端の解像度
- **両端のばらつきは鏡像**。平面図は対称面で半幅しか解かないので、上下の端は同じ区画に同じ値を引く（切り欠きも前から同じ）。
  実機の 2 つの端は独立なので、両端の割れが向かい合って並ぶのは模型の性質。本数は片端ぶんとして読む
- **割れの間隔の文献値が無い**ので、`length` の値を実機に合わせる根拠が無い。既定を 0（無効）にしているのはこのため。
  深さだけは実機の目安（0.5〜2 mm）と比べられる
- 1 本の計算では何も言えない（間隔は種で 1〜4 mm に散る）。数値を出すときは種を 5 つ以上振り、格子 2 段を併記する

## タンデム（`src/mpm/tandem.ts`）

同じ圧延をスタンドの数だけ繰り返し、材料の状態を次のスタンドへ引き継ぐ。`TandemSim(params, stands)`（1〜5）、
`node tools/tandem.mjs --stands 3`（`tools/run.mjs` と同じ引数）。

- **スタンドは 1 つずつ順に解く**（実機のように同時には解かない）。どのスタンドも同じ条件（ロール・μ・前後方張力・材料・
  板厚方向のセル数・質量スケーリング）で、圧下率はそのスタンドの入側板厚に対して r（総圧下率 1 − (1 − r)^N）。スタンドごとに新しい `Sim`
- **スタンドの読み**: `advance()` の中で `READ_STEPS`（2000、`run.mjs` の `--every` の既定）ステップごとにスタンド自身の読み
  （荷重・トルクの窓の平均、出口の板厚・先進率、相）を取る。スタンドの結果は、その読みのうち定常のものの単純平均で、`run.mjs` が同じ間隔で
  `diagnostics()` を読んで出す値とビット単位で同じ。荷重とトルクは `Sim.readWindow()`（`diagnostics()` とは別の積算）から取るので、
  画面が毎フレーム `diagnostics()` を読んでも結果は変わらない（`diagnostics()` は読むたびに平均をリセットする）。`stands = 1` は `new Sim(params)` そのもの
- **スタンドの終わり**: 次のスタンドがあるスタンドは、`advance()` の中で毎ステップ相を見て、done（または stalled）になった最初のステップで締める。
  読みまで待つと、その間（最大 1 999 ステップ）に、前方張力で引かれた板や短い板が格子の外へ出た（`docs/validation.md`「タンデム」）。
  最後のスタンドは、`run.mjs` と同じく done を見つけた読みで締める（後に移すものが無い。1 スタンドなら `run.mjs` と一致）
- **平均変形抵抗**（スタンドの結果の `meanFlowStress`、画面の「スタンドごとの結果」）: 定常の読みごとに `Sim.biteFlowStress()` = バイトの中の点の
  2k = (2/√3) σy を接触長に沿って平均（σy はその点の εp・温度、ひずみ速度はスラブ法の名目値。破壊した点は除く）。スラブ法の `twoKMean` と同じ取り方で、
  +0.1〜+0.5 %（6 セル、`docs/validation.md`「平均変形抵抗」）
- **止まる**: 最後のスタンドより前で、stalled（噛み込めない）、separated（亀裂が板厚を貫く: 隣り合う 3 列で、どの行にも破壊した点。実機の
  板切れと同じくそこで止める）、lost（格子の外に出た点がある、または板厚が測れない）なら、次のスタンドを作らずに止め、`stopped` に理由。
  スタンドの結果には、格子の外に出た点の質量の割合（`massLost`）と貫通（`separated`）を出す
- **次のスタンドの板（移し替え）**: 伸びた板の粒子をそのまま入れると、長手方向の間隔が格子（h = h0 / セル数）の 1/(1 − r)² 倍に開くので、
  新しい規則正しい格子を作り、各点に前のスタンドの点の状態を写す
  - 入側板厚 = 出た板の中ほど（格子の列の中央の半分）の今の面積 Σ vol0 J ÷ その長さ。弾性の戻りを含む（標準 6 セルで 0.7505 mm、
    隙間 0.75 mm）。一番外の点の縁で測ると（出口の計測の方法）0.3 % 薄く出る: 表層の行は内側より薄くなり、変形後の高さが行の間隔と合わない
  - 板長 = 前の板の質量 M ÷ (ρ × 入側板厚)。欠陥は置かない（空洞は閉じ、弱い部分は点の延性として引き継ぐ）
  - 写し先: 同じ格子の行（j。板厚方向の点の数はどのスタンドも セル数 × ppc）の中で、**材料の順に等分**する。新しい点は等間隔で質量も等しい
    （M / 点の数）ので、行の k 番目の新しい点は、行の古い点の同じ割合の位置（セルの中心で数えて）の点を親にする。どの古い点にも
    NI' / NI 個（± 1）の子がつく。今の位置で一番近い点を親にすると、頭端と尾端（定常でない伸び方）の点の重みが伸びの分だけ変わり、
    損傷の分布が 10〜20 % ずれた
  - 写すもの: 偏差応力（sxx・syy・sxy・szz）と圧力、εp、温度、損傷の指標（JC・HM・CL）、空孔率と塑性の体積ひずみ ev、Drucker の和、
    局所化の印、延性、破壊・亀裂の番号。速度は押し込みの速さから、APIC の勾配は 0
  - **F = √J I、ln J = ev − p / K**（von Mises は ev = 0）、vol0 = dp² / J。圧力は p = −K (ln J − ev) で J から出るので、F = I にすると
    最初のステップで圧力が 0 に戻る。この形なら写した圧力がそのまま残り、GTN の ev も塑性の体積ひずみのまま。J は 1 ± 1e-3 程度
  - 亀裂の記録は引き継ぐ（番号は通し、`stand` に生まれたスタンド）。点の数が増えるので `count` は新しい点で数え直す
  - **亀裂の面積をスタンドごとに**（2 スタンド以上のとき。1 スタンドは単発の記録のまま）: 記録の `areaByStand[k]` = スタンド k の間に
    その亀裂へ破壊した材料の面積 [m²、単位幅あたり]。面積は破壊した点の質量 ÷ ρ（移し替えで保たれる量）で、スタンドの終わりの値から
    移し替えの直後の値を引く。細かい格子で点を数え直しても（写し先の数は整数なので 1 スタンド目の 2.50e-7 m² が 2.63e-7 m² に数え直される）
    伸びにはならない。スタンドの結果に、生まれた亀裂の数 `cracksBorn` と、伸びた面積の合計 `crackGrowth`。面積には格子の外に出た点も入る
  - スタンドの結果の `nFailed`・`maxDamage` は格子の上の点だけ（外に出た点は `massLost`）。単発の `Sim.diagnostics()` の値は変えない
    （前方張力 4 セルの 1 スタンド: run.mjs の破壊した点 20、`nFailed` 4、`massLost` 10 %）
  - 格子の外へ出て止まった点（`active` が 0。前方張力で千切れて飛んだ頭端など）は引き継がない。質量の保存はその残りの板について
  - `parentOf[i]` = 次のスタンドの点 i の親の番号（画面が負荷経路をスタンドをまたいでつなぐ）。`onStandDone` で終わったスタンドの `Sim` を渡す
- **移し替えで保たれるもの**（`tools/checks/tandem.mjs`、4 セル・板長 4 mm）: 全質量（1e-12）、εp と損傷の最大値（そのもの）、εp の
  行ごと・材料の 10 分の 1 ごとの平均（1 % 以内）。損傷は、格子をまたぐ周期で列ごとに大きく変わり（高摩擦で山と谷が 10 倍）、古い 1 列が
  新しい 2 列か 3 列に写る（整数）ので、10 分の 1 ごとの平均が最大 6.5 %、行ごとが 1 % 動く
- **写した残留応力は保たれる**（前方張力が無いとき）: 移し替えの後、板が次のロールに届く前に 300 ステップ進めても、圧力・σxx・σyy の変化は rms で 6〜7 %
  （高摩擦でも同じ。残留応力は rms 65〜80 MPa、最大 110〜170 MPa）。移し替えずに前の板をそのまま 300 ステップ進めても 1.3〜2 %
  （まだ弾性の揺れが残っている）ので、移し替えで増える分は 5 % ほど。点の並びと格子の関係が変わり、離散の釣り合いが少しずれるため
  （端の近くほど大きい）。F = I の写しでは 19〜38 % 動く。動くのは主に σxy・σyy（本来ほぼ 0 で、前の格子の離散の誤差が自由表面の条件へ戻る）で、
  残留応力の本体の σxx は保たれる（表層 +140 → +137、中心 −87 → −88 MPa。レビューでの測定）。
  前方張力をかけたまま写した応力は残留応力ではなく負荷そのもので（200 MPa で中央の σxx +114 MPa）、次のスタンドで掴むまでの間は
  自由なので振れる（−104 MPa まで）。断面の平均を引いて写す案は今はしていない
- **せん断で行が傾く場合**（高摩擦、μ 0.25・圧下率 35 %）も、行は行のまま（格子の行 j は圧延を通して板厚方向の順を保つ）なので、
  行の中を材料の順に写す方式は崩れない（εp の行ごと 0.08 %、10 分の 1 ごと 0.5 %）
- **写し方の限界**:
  - 空洞（`void`）: 行の中の順番で写すので、空洞を通る 2 行は点が少ない分、ほかの行より最大 5 列ずれる。入側板厚も空洞の面積の分だけ
    1.2 % 薄く出る（面積 ÷ 長さなので）。格子の列で写す案は今はしていない
  - 高摩擦: 損傷の板全体の平均が移し替えのたびに約 1.5 % 下がる（格子の周期で鋭い山を、整数の数の点で写す標本化のため。最大値は保たれる）
  - `--nojbar`（体積の平均化なし、デバッグ用）では、移し替えの後に圧力が大きく動く（20 ステップで 25 %）
  - 後のスタンドで伸びた亀裂は、前のスタンドの記録に合流する（`stand` は生まれたスタンドのまま、`count` は細かい格子の点で数え直す）。
    伸びは下の `areaByStand` で読む
- **定常での引き継ぎ**（`handoff: 'steady'`、`--handoff steady`、`?handoff=steady`。既定は `'done'` = 上の、板が抜けてから）:
  次のスタンドがあるスタンドを、定常になったらすぐ締めて次を始める。板の残りは圧延しない
  - 締めるとき: スタンドの読みで、相が steady、定常の読みが `STEADY_READS`（2）つ以上、`steadySample()` が定常の部分を返す
  - 定常の部分 = 出側の格子の列のうち、列の平均の x が入側板厚 h0 以上（出口から板厚 1 枚ぶんで応力が落ち着く）、頭端 − 接触長 以下
    （頭端は前に板の無いままバイトを通るので、損傷が定常の部分の 2〜4 倍。`docs/validation.md`「定常での引き継ぎ」）。長さ 2 h0 以上で成立
  - 入側板厚 = 定常の部分の面積 ÷ 長さ（`thicknessOut(sim, sample)`）
  - 次の板 = **定常の部分を x 方向に繰り返したもの**（定常の圧延が作り続ける板）。古い点 1 つにつく新しい点は、質量の比 (h0 / h1)² 個で
    丸ごとの引き継ぎと同じ。引き伸ばして埋めると、板に沿って変わるもの（格子の周期の損傷の山、亀裂）の長さと板に占める割合が変わるので、繰り返す。
    繰り返しの継ぎ目では状態が不連続（定常の揺れの大きさ）
  - 板長 = `steadyLength()`: 接触長 + （頭端が 3 h0 + 接触長 に届くまで、または出口の計測点から読み 2 つぶん、の長い方 + 読み 1 つぶん）× (1 − r) + h0。
    質量は ρ h1 L（前の板の質量は保たない）
  - 届かない板（最初の板が短い）は、done まで回して丸ごと引き継ぐ（`'done'` とビット一致）。最後のスタンドは板が抜けるまで回す
  - スタンドの結果の `phase` は `'steady'`。`steps`・`t` は締めたところまで。`maxDamage`・`nFailed` は締めたときの板全体（頭端を含む）
  - 限界: 亀裂は定常の部分にあるものだけが、繰り返しの数だけ複製されて引き継がれる（記録の番号は共有、`count` は複製の合計。長さあたりの亀裂の数は保たれる）。
    頭端・尾端にだけ出る亀裂は次のスタンドへ行かない（記録は残る）。板が切れたか（separated）は締めたときの板全体で見る
- 費用: 点の数はスタンドごとに約 1/(1 − r)² 倍（25 % で 1.78 倍）、1 スタンドあたりの計算量（ステップ数 × 点の数）は 2.3〜2.9 倍。
  5 スタンドの合計は 1 スタンドの数十倍（壁時計で 4 セル・板長 3 mm が 42〜49 倍、6 セル・板長 8 mm が 50〜70 倍。計算量の比では 51 倍・79 倍で、
  格子が細かいほど大きい。既定の 10 セル・16 mm は測っていない。`docs/validation.md`「タンデム」の費用、T62）

## ロール偏平と圧下率一定（`rolling.flattening`、`rolling.gapControl`、`Sim.adjustRolls()`）

ロールは解析的な円（中心・半径・角速度）で、毎ステップ読まれる。既定は剛体・ギャップ一定（ギャップ = h0 (1 − r)）。
次の 2 つを入れると、**圧延しながら**ロールの半径とギャップを動かし、落ち着いたら止めて保持する。落ち着くまでの相は `'adjusting'`
（画面は「ロールを調整中」）で、定常の読み・タンデムの定常の引き継ぎは `'steady'` になってから。

- **ロール偏平 `flattening: 'hitchcock'`**: Hitchcock の式 R' = R (1 + C P / Δh)、C = 16 (1 − ν²) / (π E)（`hitchcockC()`。鋼のロール E 206 GPa・ν 0.3 で
  2.2498e-11 1/Pa。`rolling.rollE`・`rollNu` で変える）。P は **MPM が計算した圧延荷重**（単位幅、上下の平均）、Δh = h0 − ギャップ。
  荷重は R' で変わり R' は荷重で決まるので、連立して解く: 荷重を接触長の通過時間の 1/4 の時定数で均し、その荷重の Hitchcock の半径へ、同じ時定数で R' を寄せる
  （2 段にするのは、R' の変化率がロール面の速度として接触に入るため。1 段だと荷重のステップごとの揺れがそのまま面の速度になり、荷重が振れる）。
  偏平した弧は同じ最下点を通る半径 R' の円（中心が R' − R だけ外へ動く）。面の速度は変えない（ω = v / R'）。接触長は √(R' Δh − Δh²/4)
- **圧下率一定 `gapControl: 'reduction'`**: 出側の板厚 h0 (1 − r) を目標に、ギャップを積分制御する。20 ステップごとに、測定の遅れ（バイトから計測点まで）の半分で
  均した板厚の誤差を、遅れの 2 倍の時定数でギャップから引く。頭端が出口の計測点を過ぎてから始める（頭端は厚く波打って出るので、それで動かすと荷重が振れる）。
  ギャップ一定では板の弾性の戻りとロール偏平のぶん板が厚く出るのを消す
- **板厚は面積で測る（`Sim.areaThickness()`）**: x = h0（ロールの中心から入側板厚 1 つぶん先。0.5 h0 ではまだ 0.1〜0.2 % 薄く、h0 から先は平ら）で、
  点の今の面積（vol0 J）を Hann 窓（半幅 = 点の列 4 つぶん、0.8 h0 まで）で足して窓の長さで割る。タンデムが次のスタンドへ渡す入側板厚（`thicknessOut()` = 面積 ÷ 長さ）と
  **同じ定義**なので、スタンド k の入側板厚は h0 (1 − r)^k になる。点の外縁の 上端 − 下端（剛体・ギャップ一定のときの `exitMeasure()`）は面積より 0.1〜0.4 % 厚く読み
  （格子が粗いほど・板が波打つほど大きい）、これでギャップを決めると、渡した先のスタンドの入側板厚が目標より薄く、圧下率がスタンドごとにずれる。
  調整ありのときは、報告する出側板厚（`exitThickness`）もこの面積の板厚
- **動くロール面**: 半径とギャップが動く間、接触の相手の速度に面の法線方向の速度 (ṽcy·ny + Ṙ) n を足す（接線方向は足さない: 円の形の変化は面の物質の
  接線速度でない）。これが無いと、R' が育つ間、板がギャップより最大 20 µm 厚く出る
- **始めの値（`presetRolls()`、`Sim` を作るとき）**: スラブ法の答えから始める。偏平は `karmanFlattened()`（R' と Kármán の荷重を不動点反復で連立）を、
  荷重を 1.09 倍（薄板での MPM / スラブ法の比 1.07〜1.14 の目安）にして解いた R'。板が持ち込むひずみ（`rolling.entryStrain`。タンデムの `remap()` が
  渡す点の εp の平均を入れる）をスラブ法に持ち込むので、2 スタンド目以降も合う（R' の終わりの値との差 1〜3 %）。ギャップは h0 (1 − r) から板の弾性の戻り
  h (1 − ν²) 2k / E を引いたもの。**板はこのロールのバイトの手前に置く**（後のスタンドの R' は R の 2 倍になり、剛体のロールの接触長で置くと弧が板の中から始まる）。
  頭端が出口の計測点に届くまでは、荷重が立ち上がる途中なので、R' が追う荷重は始めの値の荷重を下回らない
- **落ち着いた、の判定**: 頭端が出口の計測点を過ぎてから、接触長の通過時間の半分の間ずっと、(a) R' が「今の荷重の Hitchcock の半径」と「自分の移動平均」の
  両方から 0.5 % 以内、(b) 板厚の移動平均（通過時間の半分）が目標から 0.05 % 以内で、今の板厚が 0.2 % 以内（板厚は点の列の格子に対する周期で揺れ、
  4 セル・r 40 % で ± 0.15 %。ギャップはそれを追うので、目標に合わせるのは平均）。満たしたらその R' とギャップの移動平均で止め（面の速度 0）、`rollsSettled`。
  標準条件で、頭端が出てから通過時間の約 1〜1.5 倍
- **タンデム**: どのスタンドも自分の入側板厚に対して同じことをする。定常の引き継ぎで渡す板は、**止まったロールを通った部分だけ**
  （`Sim.settledLength()` = 止まってからのロール面の走行距離。`steadySample()` の上端）。`steadyLength()` はそのぶん（接触長 2 つ + 3 h1）長い
- スラブ法の重ね描きは、偏平のとき `karmanFlattened()`（R' も出る。`__mpm.slab.rollRadius`）
- 限界: Hitchcock は弧を円のまま大きくするだけで、接触圧の分布による非円形の変形（Jortner、薄い硬い板で効く）は入らない。ミルの伸び（スタンドの剛性）は無い
  — 圧下率一定はギャップを直接動かすので、実機の AGC の応答ではなく「その圧下率になるギャップ」を求めるもの。止めた後は保持するので、尾端でも R' は定常の値のまま

## 3 次元モデル（`src/mpm/solid/`、画面の「3 次元」のタブ）

断面（x–y、平面ひずみ）は板幅方向の変形を 0 と置く。平面図（x–z）は板厚方向を平均する。3 次元モデル `Sim3` は x（圧延方向）・
y（板厚）・z（板幅）を全部解き、**幅広がり**と**板幅方向の荷重の分布**を直接出す。断面のソルバーとは別の計算で、断面の側は何も変えていない。

- **1/4 モデル。** 板厚の中央（y = 0）と板幅の中央（z = 0）を対称面にして、y ≥ 0・z ≥ 0 の 1/4 だけを解く。対称面は格子面に置き
  （だから板厚方向のセル数は偶数）、その外側の 1 層の節点（ゴースト）に入った運動量は、面に垂直な成分の符号を変えて鏡像の節点に畳み、
  格子の更新のあとで速度を鏡像から写す。画面は 1/4 を 2 回鏡映して板全体を描く
- **1 ステップ**は断面と同じ MLS-MPM（2 次 B スプライン、27 節点）: P2G → 格子の更新（ロールの接触、押し板）→ G2P 2 段（体積の平均化 'rate'）→
  構成則（J2 リターンマップ、Jaumann 速度、p = −K ln J）・損傷。変形勾配の体積の修正は 3 乗根
- **ロール**は z 方向に母線を持つ剛体の円柱（上だけ。下は対称面の鏡像）。接触は断面の 'surface'（ロールの面から h/2 以内の点を持つ節点）と
  同じで、近づく法線速度を消し、接線速度を Coulomb 摩擦で制限する。3 次元では接線が 2 方向（円弧に沿う向きと z）あり、すべり速度の向きに μ p を掛ける。
  これが幅広がりを抑える摩擦。点の外側の縁がロールに沈まないようにする `followRoll` も断面と同じ（無いと出側板厚が 2.5 % 厚く出た）
- **読み**（`steady.ts`、`tools/solid.mjs` と画面のワーカーで共通）: 500 ステップごと。定常（頭端が出口の計測位置を過ぎ、尾端が入口の手前）の間の
  平均を取る。荷重はロール 1 本・全幅 [N]、板幅方向の分布は格子の z の列ごと [N/m]（対称面の列は幅 h/2）、接触圧力は (x, z) の格子ごと。
  出側の板幅と板厚は、計測位置の帯にある点の外側の面（点の位置 + 変形勾配で伸びた半分の大きさ）
- **`solid.planeStrain`**: 全部の節点で vz = 0。断面と同じ問題になるので、3 次元の計算の確かめに使う（`tools/checks/solid3.mjs`）
- **`solid.fullThickness`（条件の欄の「板厚の全体を解く（ロール 2 本）」、URL `full3=1`、`tools/solid.mjs --full`）: 板厚の中央を対称面にせず、
  y を −h0/2 … h0/2 の全部、ロールを上下の 2 本にして解く（板幅の中央の対称面はそのまま。だから 1/2 モデル）。点は 2 倍、時間も 2 倍。**
  格子は y = 0 の行から上下に同じ数の行（`gyOff` = 中央の行の指標。1/4 モデルでは 1 で、行 0 がゴースト）。y の畳み込み・鏡像の写し・y = 0 の行の vy = 0・
  点の |y| への折り返しは無く、y の下限を超えた点は格子から出る。**下のロールは上のロールの鏡像**: y < 0 の節点と点は y → −y・vy → −vy にして上のロールと
  同じ式で接触（貫入・法線・Coulomb・`followRoll` の要求）を解き、答えを戻す（`sr` の符号）。ロールの荷重・トルク・z 列の荷重・接触圧力・撓みの荷重は
  2 本の和になるので、1 本の値として読むところで半分にする（`rollShare` = ½。1/4 モデルでは 1）。ゲージの板厚は体積 /（長さ × 半幅）（1/4 モデルは × 2）、
  出側の板厚は上の面と下の面の距離の半分（1/4 モデルは上の面の高さ）。タンデムの次のスタンドも全厚で作り、断面の形の y は中央を跨いで補間する。
  GPU のカーネルも同じ切り替え（uniform の `full`・`gyOff`・`yMin`）。画面は下の面を描き、y の鏡映と点線の継ぎ目を止める。
  上下対称な条件では 1/4 モデルと同じ答えになる（同じ数を同じ順で足すので 1e-13、`tools/checks/solid3-full.mjs`）。**既定は 1/4 モデルのまま**
  （`fullThickness` 無しの経路は `gyOff = 1`・`rollShare = 1`・`sr = 1` で、変更前とビット一致）。
  入力の非対称（上下でロールの径や速さ・摩擦が違う、片面の欠陥）はまだ無い: 全厚で解く価値はそれを入れたときに出る（`docs/design.md`）
- **板の長さ「定常状態になるまで」**（`rolling.lengthMode = 'steady'`、`tandem3.ts` の `steadyLength3`）: 断面の `steadyLength` と同じ式で、
  バイトを埋めるぶん（接触長）＋ 頭端が出ていなければならない長さ（3 h0 + 接触長、または出口の計測位置 + 定常の読み `STEADY_LOOKS` = 4 回ぶん、の長い方）× (1 − r)
  ＋ 読み 1 回ぶん ＋ h0。ロールが圧延に従うときは落ち着くまでのぶん（2 接触長 + 3 h0 (1 − r)）を足す。板幅には依らない。0.1 mm 単位に切り上げる
- **タンデム**（`tandem3.ts` の `Tandem3`、断面の `TandemSim` と同じ考え方）: スタンドごとに `Sim3` を 1 つずつ解く。どのスタンドも同じ条件で、圧下率は
  そのスタンドの入側板厚に対して。次のスタンドの板は、出てきた板の**板厚（体積 /（長さ × 半幅）× 2）と板幅（端の面の平均）**で作る長方形の断面の新しい格子。
  新しい点は、板厚方向は同じ行、板幅方向は同じ割合の位置、圧延方向は材料に沿って（`handoff: 'done'` = 板の全部、質量を保つ）、または定常に圧延された部分を
  繰り返して（`'steady'` = 定常の読みが 4 回と、出側に 2 h0 以上の定常の部分が揃ったらすぐ。板の長さは次のスタンドの `steadyLength3`）、親の点の
  応力（6 成分）・圧力・εp・温度・損傷の指標・破壊を受け継ぐ。F = ∛J I（ln J = −p/K）で始めるので圧力はそのまま。
  **断面の形も引き継ぐ**: 新しい点の y・z は、親の板の断面（行・列ごとの点の y・z を x 方向に平均したもの。定常の標本の範囲、または板全体なら中央の半分）を
  新しい格子の指標（板厚方向の行・板幅方向の割合）で双一次に補間したもの（いちばん外の点の中心より外は線形に外挿）。クラウン・端のふくらみが次のスタンドに入る。
  x 方向の縞（格子の周期の板厚のむら、4 セルで ±2 µm）は平均で消す: 縞を持ち込むと次のスタンドのゲージの板厚が ±0.4 % で揺れ続け、圧延に従うロールが
  落ち着かなかった（2 スタンド・定常で引き継ぎ・Hitchcock・圧下率一定で #2 の定常の読みが 0 回。`tools/checks/solid3-tandem.mjs`）（以前は長方形に作り直していて、W 6 mm で 8〜16 µm の形を失っていた。
  2 スタンド目の荷重 −0.4 %・幅広がり 7.75 → 7.54 %、`docs/validation.md`「条件を振った検証」）。**引き継がないもの**: 頭端・尾端の形、F（∛J I に戻す）、速度（入側の速さに戻す）。
  止まる理由は断面と同じ（噛み込めない・板の破断・点が格子の外）。
  1 スタンドなら `Sim3` + `SolidSampler` とビット一致
- **ロール偏平と圧下率一定**（`Sim3.adjustRolls`、制御は断面の `Sim.adjustRolls` と同じ定数）: Hitchcock の R' = R (1 + C P / Δh) の P は
  **板幅あたりの荷重** = 全幅の荷重 /（入側の板幅と計測位置の板幅の平均）。ロールは板幅方向に一様な円筒のまま（板幅方向の偏平の分布は無い。撓みは次の項）。
  圧下率一定は、出口から h0 先の**板幅全体の平均板厚**（Hann 窓の中の体積 /（窓の長さ × 半幅）× 2、`Sim3.gauge()`）が h0 (1 − r) になるよう
  ギャップを積分で詰める。端が薄い・厚い板では、板幅の中央の板厚は目標から少しずれる。落ち着くまでは `phase() === 'adjusting'` で、定常の読みはそのあとから。
  始まりは断面と同じくスラブ法の答え（`presetRolls`。タンデムの 2 スタンド目以降は持ち込むひずみ `entryStrain` 込み）
- **ロールの撓み**（`solid.rollBend`、`Sim3.updateBend`、梁は `rollBend.ts`）: ロールを直径 2R の中実の丸棒の梁とし、**バレル長**（胴の長さ）を入力、
  支点は既定でバレルの両端（`span` を与えれば軸受の中心間。胴の外に張り出したぶん撓みが増える）の単純支持。板は胴の中央。荷重は接触で節点に立った
  法線力を z の列ごとに集めた分布 q(z)（`stepFz`。対称面の列は全幅ぶんの 2 倍。Hitchcock と同じ接触長の通過時間 / 4 の時定数で均す）。
  対称なので半分だけ積分する: V = ∫q、M = M0 + ∫V（支点で M = 0）、θ = ∫M/EI、曲げの撓み ∫θ、それに Timoshenko の**せん断の撓み** ∫V/κGA
  （κ = 6(1+ν)/(7+6ν)、Cowper。ロールは D / 支点間が 1/3 ほどの太い梁で、せん断が 2 割ほど乗る）を足し、支点で 0 になるよう測る。
  E・ν はロール偏平と同じ `rollE`・`rollNu`（既定は鋼）。撓み δ(z) は**板から離れる向き**で、毎ステップ荷重から解き直して接触の
  ロールの中心 cy に足す（P2G の食い込み・格子の法線・`followRoll` の全部）。面の速度に δ の変化率も入れるので、撓む最中のロールが板を押し引きする
  仕事も入る。下のロールは対称面の鏡像なので、板は 2δ 厚く出る（板幅の中央が最も厚い = クラウン）。落ち着いたかは、板幅の中央の δ の `ctlWindow` ごとの
  平均が前の窓と 2 %（または h0 × CTL_TOL_H / 2）以内で見る（荷重の格子の周期の揺れが数 % 乗るので窓平均。定常の読みはそのあとから）。
  結果は定常の平均の δ（板幅の中央・板の端）。標準条件・W 8 mm・R 100 mm・バレル 300 mm で δ ≈ 1 µm、細いロールと広い板で効く
  （R 10 mm・W 2 mm・バレル 60 mm: δ 5.4 µm、板厚 +10.4 µm）。検査は `tools/checks/roll-bend.mjs`（閉形式との一致、通しの圧延）。
  **無いもの**: ロールの初期クラウン、バックアップロール（4 段）、板幅方向の偏平の分布、軸受のばね
- **入側の板クラウンと出側の平坦度**（`solid.crownIn`、`Sim3.ySize`、`exitMeasure`、`steady.ts` の `crownOut`・`flatness`）:
  入側の板厚を幅方向に 2 次曲線 h(z) = h0 − crownIn (z / 半幅)² で与える（h0 は板幅の中央。crownIn > 0 で端が薄い。|crownIn| < h0）。
  点の配置は列ごとに板厚方向へ詰める（`ySize[k] = h(z_k) / h0`。y = (j + ½) dp ySize、体積と質量もその分、F = I で無応力のまま）。
  点の板厚方向の大きさ dp ySize[k] は、断面積（`section`）・描く面（`surface.ts`）・出口の計測（`exitMeasure` の板厚）の全部で使う。
  タンデムの次のスタンドは入力を取り直さない（板の形は前のスタンドから持ち込む。`remap3` が `crownIn` を消す）。
  **出側の板クラウン**は、出口の計測位置（ロールから 3 h0 先）の列ごとの板厚に 2h(z) = a + b z² を最小二乗で当てて −b × 半幅²
  （列ごとの板厚には格子の縞が ±数 µm 乗るので、中央と端の差をそのまま取らない）。
  **平坦度**は形状計の読み（長手方向のひずみの差、I 単位 = 10⁻⁵）: 列 k の ε_k = ln(v_k / v_in) − σ_k / E（v_k は計測位置の列の平均の x 速度、
  σ_k は列の断面で重み付けた σxx の平均、E は K・G から）を列の平均で中心化して ×10⁵。ロールから出た直後は列ごとの伸びの差がまだ応力に
  残っているので、速度の差だけでなく弾性ぶん σ/E を引いて、その応力が解けたときの長さの差にする。**+ が伸び**（板幅の中央で + なら中伸び、端で + なら耳伸び）。
  計測位置より先では短い板の自由な先端に向けて応力が解けていくので（W 2 mm・R 10 mm で σxx が中央 +283 / 端 −421 MPa → 2 mm 先で ±100 MPa）、計測位置で読む。
  細い板（W が h0 の数倍）では板厚の差を幅広がりで逃がすので、平坦度は入側のクラウンに弱くしか依らない。剛体ロールでギャップ一定なら
  出側のクラウンは入側の大半が取れる（残りは点の大きさ dp の分解能の中: W 2 mm・平面ひずみ・40 µm → 5.6 µm）。
  グラフは 3 列の移動平均で均す（結果の表は均していない値）。検査は `tools/checks/solid3-crown.mjs`。
  **無いもの**: 入側の板の形の 2 次以外（4 次・くさび）、平坦度から座屈（実際に波打つか）の判定、幅方向の張力分布の入力
- **張力**は断面と同じ扱い（`updateTension`・`gripScale`: 端の列の実際の断面積 × 応力を、h0 の長さの掴みの点に一次の重みと点の変形後の断面積で分ける。
  掴みの点は損傷しても破壊しない。定常は張力が立ち上がりきってから）。検査は `tools/checks/solid3-tension.mjs`
- **無いもの**: GTN、亀裂の面（DFG）、欠陥。亀裂になった点は偏差応力と引張の圧力を失うだけ。
  損傷の基準は Johnson-Cook・Hancock-MacKenzie・Cockcroft-Latham
- **応力状態と負荷経路**（画面。`src/app/tracker3.ts`、断面の `tracker.ts` と同じ刻み）: 各点の (η, εp, D) を εp が 0.004 進むごと（塑性変形中に η が 0.1 変わるごと）に
  記録し、上の「破断軌跡 εf(η)」の上に描く。追う点は**最初の亀裂**（`Sim3.firstCrack.point`。破壊した時の η は亀裂の記録の値）と**損傷最大**の 2 つ
  （3 次元の絵では点は選べない）。Lode パラメータは 3 × 3 の主応力（三角関数の固有値）から。タンデムでは、後のスタンドの点の経路は `Sim3.parentOf` で親の経路に続け、
  最初の亀裂の点は前のスタンドの点の子（`childOf`）、終わったスタンドの記録は 1 点あたり最大 24 本に間引いて持つ。検査は `tools/checks/tracker3.mjs`
- **費用**: 点の数は板幅 × 長さ × セル数³ に比例する。標準条件・板幅 8 mm・長さ 12 mm・4 セルで 1.2 万点、約 2.5 分（Apple M2）。6 セルは 4.1 万点で約 14 分
- **使える範囲**: 板幅 / 接触長が 1〜数倍の狭い板（幅広がりが大きい領域）。実機の広幅の板（W / Lc > 100）は幅広がりがほぼ 0 で、断面（平面ひずみ）で足りる。
  出てきた板の表面の相当応力に格子の周期の縞が出る（点が格子を横切る誤差。断面にもある）

### GPU（WebGPU、`src/mpm/solid/gpu/`、条件の欄の「計算」）

3 次元の 1 ステップを WebGPU の計算シェーダで解く。`Sim3` は状態の入れ物のまま（配列・制御・読みは CPU 側）、`GpuStepper` が
デバイスのバッファとカーネルを持ち、`Sim3.advanceBatch(K)` が K ステップ（≤ CTL_EVERY = 20、CTL_EVERY の倍数で終わる）をまとめて回す。
バッチごとに全点の状態を読み戻して `Sim3` の配列に写すので、色の量・応力状態・定常の読み・タンデムの引き継ぎは CPU と同じコードで動く。

- **カーネル**（WGSL、`kernels.ts`）: P2G（散布は浮動小数の原子加算を CAS ループで）→ 折り返し（対称面）→ 格子の更新と接触（ロールへの侵入の
  最小は順序を保つ整数キーの atomicMax）→ ロールに追従する点（`followRoll`: 点ごとの散布と節点ごとの解決の 2 段）→ 鏡映と荷重の和 → G2P の速度 →
  体積の平均化 → G2P の更新（F・Jaumann・J2 リターンマップ・断熱昇温・損傷・破壊）。1 ステップ 9 回のディスパッチ、格子は 1 つの `array<atomic<u32>>`
- **単精度**: 侵入量 d − R − rp は f32 では桁落ちする（d ≈ R ≈ 0.1 m、侵入 10⁻⁸ m）ので、e = y − gapHalf − 撓み(z) から
  pen = (x² + e(e − 2R)) / (d + R) − rp と書く（gapHalf = cy − R を一様変数で渡す）。これで接触の判定が CPU と同じ点で入る。
  塑性の Newton の許容は 1e-6（相対）。同じ条件でも原子加算の順序が変わるので**ビット一致はしない**（CPU は毎回同じ）
- **制御はバッチに 1 回**: ロール偏平・圧下率一定（`adjustRolls`）と撓み（`updateBend`）は K ステップ分の dt（dtEff = K·dt）で 1 回。
  荷重の低域通過はバッチの平均の荷重で、押し込みの制御（`ctlForce`）も同じ。停止の判定（200 ステップごと）はバッチにその倍数が含まれるとき。
  1 ステップずつ回した場合と結果は同じ範囲（`docs/validation.md`「GPU」）
- **GPU が無いとき**: ワーカーがアダプタを取れなければ CPU で計算し、条件の欄の「計算」の下にその旨を出す（`geometry.gpuNote`）。
  デバイスが失われたら止まって知らせる。デバイスはワーカーで 1 つ、やり直しても持ち越す
- **速さ**（Apple M2）: 板幅 8 mm・4 セルで CPU 7.8 ms/step → 1.0 ms/step（8 倍）。板幅 2 mm では 2.7 倍（読み戻しとディスパッチの固定費が効く）
- **どの GPU でも**（NVIDIA・AMD・Intel・Apple、Vulkan / Metal / D3D12）: WebGPU の既定の制限の中だけで書く（バインドグループ 1 つに
  バッファ 5 本、64 幅のワークグループ、浮動小数の原子加算・サブグループ・f16 は使わない）。デバイスはアダプタ自身の上限
  （`maxStorageBufferBindingSize`・`maxBufferSize`・`maxComputeWorkgroupsPerDimension`）で要求し、板の格子と粒子がその上限を超えるときは
  `GpuStepper` が作られる前に `gpuFit` が理由（どのバッファが何 MiB で上限が何 MiB）を返して CPU に退避する。65535 ワークグループを超える
  ディスパッチは 2 次元（`tid()` が行と列から番号を出す）。`select` の捨てる側の引数（log・pow・除算）は clamp してあり、どちらの枝も
  Inf・NaN を作らない（選ばれる側の値は同じ）。点のステンシルが格子の外に掛かる点は触らない（負の添字が u32 で巻くのを防ぐ。CPU は
  そういう点を更新で非活性にする）。アダプタは `powerPreference: 'high-performance'`（内蔵と外付けがあれば外付け）。
  結果の表と選択の下に vendor・architecture・backend が出る。許容は Apple M2 で校正した（`docs/validation.md`「GPU」）ので、別の GPU では
  `gpu.mjs` を回して同じ帯に入ることを確かめる
- **複数の GPU**: WebGPU は GPU の一覧を出さない（`powerPreference` で「高性能」「省電力」を頼めるだけ）。`requestGpuPool()` はその 2 通りで
  取れる**別々の**アダプタをデバイスにして返す（外付け + 内蔵の機械で 2 つ、同種の GPU が何枚あっても 1 つ）。1 回の圧延を複数の GPU で
  分けることはしない（格子を毎ステップホスト経由で交換することになり、1 つで解くより遅い）。独立した仕事（条件を変えた複数の圧延）を
  プールの中で回す形で使う（`tools/gpu/check.ts` の `passesAll`）。同種の GPU を何枚も使う機械では、Chrome を GPU ごとに別に上げるのが
  現実的な使い方（Linux は `BROWSER_GPU_FLAGS` で Vulkan の旗を変える）
- **無いもの**: 2 次元（断面・平面図）の GPU、f16

### メモリ

粒子は 2 次元 338 B/点（Float64 40 本 + Int32 3 本 + Uint8 6 本）、3 次元 364 B/点（Float64 45 本（C・F が 9 本ずつ）+ Uint8 4 本）。
格子は 2 次元で節点あたり 8 B × 11 本 + 2 NN の 4 本（`dfg` で NN が 2 倍）、3 次元 114 B/節点（`Grid3` 16 本）。既定の条件でどちらも数 MB
（`docs/validation.md`「メモリ」）。ステップの中で配列を作らない（2 次元の `followRoll` が触れる点ごとに作っていた重みの配列も
`swx`・`swy` に）。大きいのはページ側:

- **3 次元の巻き戻しの記録**（`tape.ts`、最大 400 枚・160 MB）: 1 枚が面の頂点と値（色の量 10 通りぶん、既定で約 220 KB）。荷重の履歴はフレームごとに全部を
  複製して記録の各枚にも持っていた（記録の枚数 × 履歴の長さ）ので、ワーカーは前のフレームから増えた行だけ送り（`history.from`）、ページが
  1 本の履歴に足す。各枚はそこまでの長さ（`historyLen`）だけ知っている
- **スレッド**: ワーカーごとに格子の写しを 1 つ持つ（`size + 1` 個。8 スレッド・板幅 8 mm で 38 MB）。粒子は共有で増えない
- **GPU**: 粒子 208 B/点（f32 52 本）+ 読み戻しの写し、格子 80 B/節点、和 8 B/節点。上限との照合は `gpuFit`
- **動画**: 記録の枚数ぶんの符号化したフレームを持ち、mux で連結する（数 MB × 3〜4 が一時的に）

### CPU の複数スレッド（`src/mpm/solid/team.ts`、条件の欄の「CPU のコア数」）

CPU の 1 ステップを N 本のスレッドで分けて解く。状態は `SharedArrayBuffer` に置き（`Sim3Options.shared`）、`Sim3` を持つスレッド（画面のワーカー、
または `tools/solid.mjs`）が**調整役**（rank 0）として自分の分も解き、ほかの N − 1 本（ブラウザの Worker `solid.helper.worker.ts`・node の
`worker_threads` `tools/lib/solid-helper.mjs`）は同じ配列に `Sim3` を貼り付けて（`Sim3Options.attach`）自分の分だけ解く。

- **分け方**: 点を基準セルの列（x の格子の列 `bx`）で連続した区間に分け、列の境界は 20 ステップごとに点の数のヒストグラムで釣り合わせる。
  節点も同じ列で分ける（区間 [pLo, pHi) の点は節点 [pLo, pHi + 2] に散布するので、境界の 2 列は隣と共有）
- **散布は自分の格子へ**: 各スレッドは自分の点を自分の格子の写し（`g`）に散布し、列の持ち主が主格子 `G` に足す（`G[c] = g[c] + left[c]`: 左隣の写しの、
  自分の最初の 2 列だけ。質量・運動量は和、侵入量は最小、押しの旗は OR）。格子の更新・追従・G2P は G から。足し算の順序が 1 本のときと違うので**ビット一致はしない**が、
  結果は 1e-9 で一致する（`tools/checks/solid3-threads.mjs`）。1 本のときは `g === G` で、以前と同じ計算
- **点の持ち主は散布で決める**: 各点の持ち主（rank + 1）を P2G で共有の `owner` に書き、追従・G2P の段はそれを読む。位置から決め直すと、
  G2P の更新で隣のスレッドが先に動かした点を自分の列と見て二重に更新する（直列に回すと必ず、並列では 3 回に 1 回ほど荷重が 1e-5 ずれた。
  `Team` の `serial`（調整役のスレッドで全員の分を順に回すデバッグ用）で毎回再現して直した）
- **段と関門**: 1 ステップは 7 段（P2G → 格子の更新 → 追従の散布 → 追従の解決 → G2P の速度 → 体積の平均化 → G2P の更新。`grid3.ts` の `PH_*`）で、
  段ごとに `Int32Array` の関門（世代・段・済んだ数、`Atomics.wait` / `notify`）。ステップの間はメッセージを送らない。調整役は段の前に同期の塊（ロールの位置・
  速度・張力の立ち上がり・時刻・列の境界、`SY_*`）を書き、各スレッドは部分和（荷重・トルク・仕事・破壊した点の数と最初の点、`PT_*`）を書き戻す
- **スタンドの切り替え**: 新しい `Sim3`（`remap3`）を貼り付け直すには各スレッドがイベントループに戻っている必要があるので、調整役が関門で「抜ける」を出してから
  `postMessage` で配列を送る（`Team.attach`）
- **要るもの**: `SharedArrayBuffer` はページが cross-origin isolated のときだけ使える。`vite.config.ts` が dev / preview に
  `Cross-Origin-Opener-Policy: same-origin` と `Cross-Origin-Embedder-Policy: require-corp` を付ける（Google Fonts の `<link>` は `crossorigin`）。
  付かないところ（静的な配信）では 1 本で計算し、条件の欄にその旨を出す（`geometry.threadsNote`）。GPU を選んだときは使わない
- **速さ**（Apple M2、P 4 + E 4）: 板幅 8 mm・4 セルで 1 本 7.2 ms/step → 2 本 4.5 → 4 本 2.9（2.4 倍）→ 8 本 2.9。関門で遅い E コアを待つので
  4 本から先は伸びない。板幅 2 mm では 3 本で 1.9 倍

## 既知の限界（改善の候補）

- **体積ロッキング**: 上の「体積の平均化」（'rate'）で抑えている（ロールの近くの係数は T27 で 1 に戻した）。
  T21 の時点（接触 'stencil'）では、粒子の尺度の圧力のむらが以前の J-bar より大きく（バイト内の隣との差の平均 6 セルで 23 対 12 MPa、
  10 セルで 13 対 6）、損傷の指標が 1.5〜2 倍だった（標準の最大損傷 0.011 対 0.006）。T27 の接触の後は標準の最大損傷が 0.0056 / 0.0089
  （6 / 10 セル）で、以前の J-bar（0.006 / 0.010）と同じ程度に戻った（`docs/validation.md`「標準条件」。圧力のむらは T27 の後に測り直していない）。厚板の中心の σm/2k はまだ格子で動く（8/12/16/24/32 セルで
  −0.11 / +0.04 / +0.13 / +0.20 / +0.23、J-bar なしと同じ傾向、Hill の +0.39 への外挿は未確定）。校正は `tools/checks/volumetric*.mjs`
  と `rolling-smoke.mjs`（荷重の上限 5 kN/mm でロッキングを落とす）
- **接触**: 'surface'（上の「接触」）でも拘束は最寄りの行までかかるので、最外層の粒子はロールの圧力の 9 割前後を受け持つ
  （6 セル 0.88、10・14 セルでは 1.0 前後）。荷重・分布は節点の力積から出す。表層の行の薄くなり方は格子でまだ揃いきらない
  （'rate'・10 セルで 表層 / 1/4 / 中心 = 0.39 / 0.34 / 0.32、14 セルで 0.36 / 0.32 / 0.33。以前の J-bar 'total' では 10 セルで 0.46 / 0.29 / 0.30）
- **質量スケーリング**: 既定 1e4 倍（周速 1 m/s）。準静的の目安を `Diagnostics` に出す（結果の表の「慣性 / 塑性仕事率」）:
  条件から決まる `inertiaRatio` = ρ ms V² r / 2k̄（標準で 4.5 %）と、定常で測る `kineticRatio` = ロールが板に与える運動エネルギーの流束
  ṁ(v1² − v0²)/2 / 塑性仕事率（標準で 12 %）。1e4 では荷重・出側板厚・先進率はほぼ変わらないが、トルクには慣性の分（約 8 %）が乗る。
  1e5 では荷重が −6 %、トルクが +60 % 以上動き準静的でない（`docs/validation.md`「準静的と荷重の振動」）
- **荷重の細かい振動**: 粒子の列が格子をまたぐ周期 2h/v_in（入側速度）の数値的な揺れで、弾性波ではない（周期が質量スケーリングによらず格子に比例する）。
  10 ステップごとの荷重で標準偏差 3 %（6 セル）、2000 ステップの平均では 0.1 % 未満。減衰では消えないので入れていない
- **噛み込み不良**: 押し込み装置を外した後、板全体の平均速度が周速の 5 % 未満のまま、ロールが接触長を進む時間続いたら phase を `stalled` にして止める
  （μ 0.005 で止まる。μ 0.02 は噛み込み角 α/2 ≈ 0.025 より小さいが、減速しながら最後まで圧延される）
- **亀裂の開口**: 既定の 'dfg'（上の「亀裂の面」）では亀裂の近くで速度場を 2 つに分けるので面は開く。`numerics.crackFields = 'none'`
  に戻すと速度場が 1 つになり、破壊した粒子の両側が格子を通じて同じ速度に引っ張られて、面の隣が荷重を持ち続ける（T74 までの既定）。
  'dfg' でも、二次の B スプラインの台より細い亀裂では分かれ方が格子に依存する（上の「亀裂の面」の限界）
- **2D**: 板幅方向が無いので、耳割れ（エッジクラック）は扱えない（板幅は平面図モデル `src/mpm/planview/` で。上の節）
- **剛体ロール**: ロール偏平（Hitchcock）は無い
- **圧縮を受ける破壊した点の圧力**（T46 で直した）: 'rate' で破壊した点が自分の tr L で J を進めていたときは、格子の点ごとの tr L の
  むらがそのまま体積に乗り、圧縮で閉じた亀裂の点の圧力が、切っていない板の同じ点の 1.7〜3.6 倍（最大 2.5 GPa。T21 の時点は 3.15 GPa）になった。
  今は、**圧縮を受けている（p > 0）破壊した点は体積の平均化に入る**（散布して読む）。引張の破壊した点は今までどおり自分の率で、平均に入らない
  （開く亀裂が健全な隣を膨らませないため）。平均を読むだけで散布しない案は、破壊した点には偏差の剛さが無いので、その点の体積のずれに逆らう
  ものが無くなり、閉じた帯がバイトの中で発散した（ステップごとの tr L の積分が 0.1 → 4.5、そのあと NaN）。
  副作用: 開いた亀裂の帯の体積の増え（ln J）が、閉じた帯を通した後で +0.064 → +0.095 になる（圧縮の間は平均に、引張の間は自分の率に
  従うので、増える向きに溜まる）。破壊した点は引張で応力を持たないので、力には効かない。検査は `tools/checks/failed-pressure.mjs`
- **GTN の圧力のむら**: 以前の J-bar（'total'）では J̄ を平均し ev を平均しないので K Δev のむらが出た（常に核生成でバイト内の隣との
  差の最大 347 MPa）。'rate' は弾性の体積だけを緩和するので 88 MPa（`tools/checks/volumetric-gtn.mjs`）
