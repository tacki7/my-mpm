# デザイン

## 対象と役割

- 使う人: 圧延・塑性加工の技術者と研究者。数値と単位を読み、条件を変えて比べる
- 画面の主役: **ロールバイト**。板がロールに噛み込み、薄くなって出ていく様子と、その中の応力状態
- 仕事: 条件を変える → 圧延を見る → どこで・どんな応力状態で亀裂が生まれたかを読む

## 方向性 — ミルシート（鋼材検査証明書）

冷延鋼板に付く検査証明書の紙面を下敷きにする。冷たい灰緑の紙、藍墨の文字、表組み。
**朱の検査印は亀裂にだけ使う**（ロールバイト上の亀裂位置と、亀裂の記録の番号）。
損傷の色は鋼の焼戻し色（麦わら → 茶 → 紫 → 青）。「損傷が進む」ことを鋼の色の変化で見せる。

| 名前 | 値 | 用途 |
|---|---|---|
| 紙 | `#e6e9e7` | 背景 |
| 台紙 | `#f4f5f3` | 条件・結果の面、入力欄 |
| 藍墨 | `#1d2a3a` | 文字、罫、主ボタン、破壊した粒子 |
| 鋼 | `#8a949c` | ロール、補助の罫、参照の線（スラブ法）。字には使わない（台紙の上で 2.8:1） |
| 鋼の字 | `#5f6b75` | 鋼の色で書く字（平面図の直前の読み）。台紙の上で 5.0:1 |
| 検査印 | `#c23b22` | 亀裂だけ |
| 焼戻し色 | `#e3cf86` → `#c99a4a` → `#8d5a33` → `#6b3f7a` → `#2c4a8c` | 大きさだけの量（損傷、塑性ひずみ、相当応力） |
| 圧縮・引張 | 青 `#1f3f7a` ↔ 灰 `#c5ced3` ↔ 銅 `#9c4a1c` | 符号のある量（三軸度、主応力、静水圧） |

## 文字

- 本文・UI: BIZ UDPゴシック（業務文書向けの UD 書体。数字は等幅 `tabular-nums`）
- 見出し: しっぽり明朝 B1（証明書の表題の格）
- 等幅書体は使わない。ラベルを大文字化しない。見出しの上に飾りのラベルを置かない
- 文は短く、ユーザーの言葉で（「P2G」ではなく「計算」、「phase」ではなく「噛み込み中」）

## 配置

```
┌ 表題 ─────────────────────────── 条件 [圧延を始める][一時停止][やり直す]  t = … ┐
├ 条件 ────┬ 色で表す量のタブ ─────────────────────────────┬ 圧延結果（表）──┤
│ 板とロール │                                                │ 圧延荷重 …       │
│ 潤滑と張力 │            ロールバイト（主役・最大）            │ 出側板厚 …       │
│ 材料       │                                                ├ 亀裂の記録 ──────┤
│ 破壊の基準 ├ 圧延荷重の推移 ───────┬ フリクションヒル ────────┤ ① 12.4 ms 板厚中心│
│ 計算       │                      │                          │   η 0.62 σ1 …    │
└──────────┴──────────────────────┴──────────────────────────┴──────────────────┘
```

右列の「圧延結果」の下に「応力状態」（選んだ点・最初の亀裂・損傷最大 の切り替えと、その点の応力の表）。
グラフの列の 3 つ目が「破断軌跡 εf(η) と負荷経路」。点の色は 選んだ点 = 藍墨、最初の亀裂 = 検査印の朱、損傷最大 = 焼戻しの茶。
ロールバイトの左上に表示の操作（＋ − 元に戻す、板厚方向の倍率 自動・1・2・4、主応力の向き）、右下に板の全長の俯瞰
（今の表示範囲を枠で。クリックでそこへ）。ホイールで拡大、ドラッグで移動、ダブルクリックで元に戻す。キャンバスに
フォーカスがあれば + − 矢印 0。主応力の向きは十字（銅 = 引張、青 = 圧縮、長いほど大きい。明るい縁取りで地の色から浮かせる）。
粒子は変形勾配で写した平行四辺形で描き、隣と 1 px 重ねて継ぎ目を出さない。

グラフの線: 主の量は藍墨の実線（荷重はその移動平均）。1 フレームの平均は藍墨を薄く細く残す（格子をまたぐ揺れが見える）。
MPM の圧力 p は青の実線、摩擦応力 τ は銅の破線。参照（スラブ法、Kármán）は鋼の細い線で、荷重と p は破線、τ は点線、
中立点は白抜きの丸。参照は控えめに（主の線より細く、色は鋼だけ）。参照の方法の外の条件（張力が 2k に達する・固着・
中立点がバイトの中に無い。入口側か出口側かを理由に書く）では線を出さず、凡例に理由を 1 行。凡例はグラフの下に線の見本（実線・破線・点線・細線・丸）と名前を並べ、
狭い幅では折り返す。差の読み方（格子が粗いと MPM の荷重は高く出る）は荷重の凡例の下に注として 1 行。

**断面と平面図の切り替え**: 表題の右、条件の選択の左に「断面」「平面図」の 2 つのボタン（押されている方を藍墨で塗る）。平面図では
ロールバイトとグラフの列の代わりに、上から見た板（圧延方向 x を右、板幅 z を上。解くのは半幅で、板幅の中央で鏡映して全幅を描く）。
ロールの接触は入口から出口までの鋼の薄い帯と破線、板幅の中央は細い破線。色の量のタブは 圧延方向 σxx・板幅方向 σzz・相当応力・
三軸度・損傷・幅広がり（板幅方向の変位、外向き +）。色の規則は断面と同じ（符号のある量は青 ↔ 銅、大きさだけの量は焼戻し色、
亀裂になった点は藍墨、亀裂の番号の印だけが朱）。右列は「圧延結果（平面図）」「亀裂の記録（平面図）」「結果の書き出し」
（条件の URL だけ）。結果の表の定常の値がまだ無い間は、直前の読みを鋼の字（薄い字）で出し、表の下に注を 1 行。
条件パネルの頭に「板幅（平面図）」（板幅・半幅のセル数・端の切り欠き）を、平面図のときだけ出す。

**タンデム**（スタンド数 2 以上）: ロールバイトの枠をスタンド数ぶんに等分して横に並べる（区切りは 1 本の罫。720 px 以下では縦に
積み、1 つあたり 240 px の高さ。表示の操作と俯瞰の帯の下から並べ、#1 の板に重ねない）。計算中のスタンドの枠に本物のロールバイトの絵を移し（操作・俯瞰・凡例は枠全体の同じ位置のまま）、終わったスタンドは
定常中の絵（板が表示窓いっぱいに入ったところ）を残す。パスが終わると最後のスタンドも定常中の絵にする（数値は終わりの状態）。枠の左上にスタンドの番号（計算中は藍墨の太字、他は薄い藍墨）。縮尺（最初のスタンドの板）と色の範囲は並んだ絵で共通にして、
スタンドの間で比べられるようにする。スタンドの色は #1 薄い藍墨 `#4b5a68`、#2 緑青 `#387262`、#3 紫 `#6b3f7a`、#4 黄土 `#7a6518`、
#5 紅紫 `#a44478`（朱は亀裂だけ、銅は「損傷最大」の茶に近いので使わない。隣のスタンドどうしは色相を離す。どれも字として台紙の上で 5:1、紙の上で 4.5:1 以上。
以前の黄土 `#b08a2e` は台紙の上で 2.9:1 だった）。番号の点のラベルは紙の色で縁取る。負荷経路はスタンドごとにこの色で、始まりに番号付きの点。右列の「スタンドごとの結果」は
スタンドを列にした表で、列の見出しをスタンドの色、計算中の列は下線。荷重のグラフのスラブ法はスタンドごとの段にして、段の頭に `#k`。

条件パネルの「材料の定数」（折りたたみ。加工硬化の則と定数、流動応力の小さな曲線。材料の値から変えると「カスタム」）と
「欠陥」（空洞・弱い部分の一覧。追加・削除）。範囲外の入力は枠を暗い赤 `#9b2c2c`（亀裂の朱とは別）にし、範囲と
「このままだと何で計算するか」を 1 行で書く。

左揃え。面は影や角丸のカードにしない。区切りは余白と 1 本の罫。

## 原則

- 大胆さはロールバイトの描画 1 か所に使う。周りは静かな計器と帳票
- 板厚方向の誇張表示は必ず倍率を明記する（「板厚方向を 3.0 倍に拡大して表示」）
- 数字には必ず単位。桁は揃える
- 動きは状態の変化にだけ（ロールの目盛りが回る、亀裂の印が現れる）。自動で動く飾りは入れない
- **印象に残す瞬間は 1 つ: 亀裂が生まれたときの検査印。** ロールバイト上の朱の印は大きく薄く降りてきて、少し回って
  定着し、着いた瞬間に朱のにじみが 1 回だけ広がる（420 ms）。亀裂の記録の同じ番号の印も同じ動きで押される。
  `prefers-reduced-motion` では動かさない
- 色だけに頼らない: 亀裂になった粒子（藍墨）は凡例に文で書く。亀裂の記録は読み上げ（`aria-live`）で知らせる
- 字は下地と 4.5:1 以上（WCAG AA。大きな字は 3:1）。ロールバイトの絵の上の字（状態の行・凡例・スタンドの番号）は、表示の操作と同じ
  台紙の色の下地（不透明度 0.9）に置く（ロールの奥は暗い鋼色 `#6f7a82` で、藍墨でも 3.3:1、薄い藍墨では 1.6:1）。`tools/browser/a11y.mjs` で測る
- 状態の行（ロールに向かっている・噛み込み中 …）は表示の操作の行の右端。狭い絵では操作の下に折り返し、操作に重ならない。読み上げ（`aria-live`）は
  文面が変わったときだけ書き換える（同じ文面を毎フレーム書き直すと、読み上げが繰り返されうる）
- 表示の操作の押す場所は 24 px 以上（WCAG 2.5.8。下の絵もクリックを受けるので間隔では足りない）
- 1100 px 以下で 2 列（右列の結果・亀裂の記録・応力状態は下に横並び）、720 px 以下で 1 列（ロールバイト → 結果 →
  詳しい条件の順。条件の選択と操作のボタンは表題の行に残る）。キーボードのフォーカスを見せる（藍 `#2c4a8c` の 2 px の枠。絵の上の部品は
  枠の外側に台紙の色の縁 5 px を足して暗いロールから浮かせる。ロールバイト自身の枠は絵の内側に描く（外側は両脇と下の分割線に隠れる））
- 色で表す量のタブ・平面図のタブ・応力状態の「選んだ点／最初の亀裂／損傷最大」は、それぞれ 1 つのラジオの組: Tab 1 回で選ばれているものに入り、
  矢印（← → ↑ ↓）で隣へ（端からは反対の端へ）、Home・End で端へ。Tab で一巡するのに 14 のタブを 1 つずつ通らない
- 色で表す量のタブは 1 行。入りきらない幅では横に送る（右端を薄くして続きがあることを示す）。長い名前はタブでは短く
  （「圧延方向 σxx」）、凡例では正式な名前
- 条件パネル: よく変える板・ロール・潤滑・張力・材料・破壊の基準を上に。空孔（GTN）と計算の設定は折りたたむ
- 右列は 圧延結果 → 亀裂の記録 → 応力状態 の順（亀裂の記録を画面の中に）
