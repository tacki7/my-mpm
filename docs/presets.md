# 名前付きの条件

`src/mpm/presets.ts`。それぞれ「見せたい現象」と、その現象が実際に出るかの状態。

| id | 名前 | 見せたい現象 | 状態 |
|---|---|---|---|
| `standard` | 薄板の標準圧延 | 圧縮の三軸度が支配的で割れない | 確認済み（6・10 セルで破壊 0、最大損傷 0.006〜0.010） |
| `front-tension` | 前方張力が過大 | 出口の先で板がくびれて破断 | 確認済み（4・6・8 セルで出口と頭端の掴みの間が破断。下の「前方張力」） |
| `central-burst` | 厚肉・軽圧下の中心割れ | 変形が板厚中心に届かず、中心に静水圧の引張 | 未調整 |
| `void` | 内部欠陥（空洞）起点 | 空洞がバイトで潰れるか、出口側で開くか | 未調整 |
| `high-friction` | 高摩擦・低延性 | 表層から割れる | このモデルでは出ない（下の「高摩擦」）。割れずに圧延される例として残す |

「未調整」は、数値を当て推量で入れただけのもの。現象が出る条件を探して、ここに測定条件と結果を書く。

## 前方張力（`front-tension`）

SPCC、圧下率 35 %、μ 0.15、前方張力 580 MPa、Cockcroft-Latham 0.35。

**破断の条件**: 出口の先の板が降伏すること。圧延後の板の平面ひずみの変形抵抗 2k（スラブ法で出口の値）は圧下率 25 % で 511 MPa、35 % で 557 MPa。
張力がこれを超えると出口の先の板が塑性で伸び、くびれて（板厚 0.755 → 0.667 mm、εp 0.38 → 0.57）、くびれで η 0.6〜0.65 の引張のまま損傷が溜まって割れる。
ただしロールが板を引き留められる張力には上限があり、スラブ法で中立点が入口に達する（スキッド）前方張力は、後方張力 0 のとき
圧下率 25 %・μ 0.08 で 405 MPa（< 511）、35 %・μ 0.15 で 598 MPa（> 557）。標準の形ではスキッドせずに出側を降伏させる張力は無いので、
プリセットは 35 %・μ 0.15 にした（557 < 580 < 598）。MPM でも中立点は噛み込みの中（接触長 5.91 mm に対して −3.6 mm）。
先進率は 27〜29 %（スラブ法 38 %）で、0〜10 % には収まらない: 前方張力で中立点が入口側へ寄るうえ、出口の先の板が塑性で伸びるので
出口の先で測る速さが上がる。先進率 10 % 以下になる前方張力（スラブ法で 181 MPa 以下）では出側は降伏せず割れない。

**張力の閾値**（`presetById('front-tension')` の前方張力・形・格子だけ変え、最初の亀裂 `sim.cracks[0]` が出るまで回した。板長 16 mm、質量スケーリング 1e4、2026-09-19、負荷の高い M2・Node 24.14）。

- 閾値は出側の 2k の 0.99〜1.2 倍（35 %: 6 セルで 540〜550、8 セルで 560〜580 MPa。25 %: 550〜600 MPa）。格子で 1 段（20 MPa 程度）動く
- 破断の位置は出口と頭端の掴みの間。閾値のすぐ上では板の中ほど（頭端から 5 mm）、張力が高いと掴みのすぐ外（頭端から 1.0 mm）。
  質量スケーリング 1e4 では、ロールで引き留めた板を張力が加速するので張力は頭端側ほど高い（出口 540 → 頭端 600 MPa）。
  1e3 にすると破断は出口寄りになる（35 %・560 MPa・6 セルで出口の先 1.4 mm、頭端から 3.0 mm。25 %・600 MPa で頭端から 1.3 mm）。
  準静的な実機でどこが切れるかは、この計算からは言えない
- 板厚方向の位置は格子で違う（6 セルで中心から 0.18〜0.30 mm、8 セルで中心）。三軸度の結論は T21 の後に確かめ直す
- 以前（張力を頭端の 1 列に線荷重でかけていたとき）は 450 MPa 以上で最初の亀裂がいつも頭端の列（頭端から 0.125 mm）に出た。
  これは人為的なもので、張力を掴み（頭端・尾端の長さ h0）に分けてかけ、掴みの中では破壊させないようにした（`docs/model.md`「張力」）
- 検査: `tools/checks/presets-tension.mjs`（4 セル、約 20 秒）

## 高摩擦（`high-friction`）

Al 6061、μ 0.25、圧下率 35 %。表面割れは出ない。表層（格子の上下の端の粒子の列）の三軸度は、入口の手前から出口の先までどこでも負
（6 セルで最大 −0.27、10 セルで −0.28。出口の先は −0.35〜−0.45）で、最大損傷は 0.11（6 セル）・0.14（10 セル）。理由の候補:

- 表層の相当塑性ひずみが板厚中心より小さい（6 セルで 0.32 対 0.78、10 セルで 0.35 対 0.58）。高摩擦なら表層は余分なせん断で中心より
  大きくなるはずで、ロールに食い込む粒子を持つ節点すべてを拘束する接触（表面から約 1.5 セルの帯）が表層をロールと一緒に運んでいる
  （`docs/model.md`「既知の限界」の接触）。格子を細かくすると差は縮む
- 平面ひずみの σzz の不整合（T21）で、応力がほぼ 0 の出口の先でも η が −0.3〜−0.45 になっている

表面割れが出る条件も探した（6 セル）: 後方張力 200 MPa を足すと入口の手前の表層が引張（η 0.14〜0.37、ただし弾性）になり、
塑性が始まる入口付近の表層に損傷が 0.15 溜まる。延性を下げて（Johnson-Cook の D2 を 1.45 → 0.9）も、割れたのは頭端がバイトに入った瞬間の頭端
（頭端から 1.1 mm、板厚の 1/4 位置）で、定常の表面割れではなかった。D2 1.0 では割れない（最大損傷 0.97）。後方張力なしで D2 0.9 も割れない。
